# Lumio Web 工作台

中文 Web GUI，连接既有 Hub，覆盖知识阅读、项目任务、执行、助手与审批。浏览器只通过 `@lumio/api-client` 调用既有契约，不直接访问业务库或 vault。

## 试用

不想动已安装的 Hub 时，在仓库根目录运行 `bun run demo:web`：会启动一个用合成数据的临时 Hub（网页与 API 共用端口 7499），终端里打印访问地址和令牌。助手使用本地假模型。Ctrl+C 退出并删除临时数据。

## 启动

安装后打开 Hub 地址（单机默认为 `http://127.0.0.1:7420`）。源码开发在仓库根目录运行（Bun 版本以根目录 `package.json` 的 `packageManager` 为准）：

```sh
bun apps/cli/src/main.ts hub serve
```

网页由 Hub 提供，没有单独的 Web 服务或端口。在已配置的 CLI 上运行 `lumio login-code --name web`，输入一次性配对码；也可输入已有 human 令牌。默认刷新当前标签页会自动恢复登录；勾选「记住这台设备」后，在同一个浏览器中关闭重开也能恢复。只在自己的设备上勾选。配对码要求 Hub 已配置对外地址；未配置时 CLI 会给出设置说明，已有 human 令牌仍可直接连接。

默认 Hub 为 `http://127.0.0.1:7420`。使用包含 v2 Work/Execution/Assistant API 的 Hub；知识旧笔记与数据库工作是不同视图，旧任务需按[迁移说明](../../docs/migration-v2.md)显式切换。Web 不自动迁移或升级已有服务。

## 功能

- 今日：一句话总览推进中/待办/正在运行/等你决定的数量；下面是任务、需要处理的运行与审批、运行动态和项目进度。各区块独立显示错误。
- 工作（项目与任务）：任务按「轮到谁」分组（需要你处理、你的待办、agent 在做、在等外部、已搁置、已完成），边输入边搜索，按轮到谁和项目筛选；列表上点图标即可交回、搁置、完成或取消。详情里的属性（轮到谁、项目、截止、执行设置）点选后立即带版本保存；标题、说明各自保存。任务页有交接计划（进度与编辑器）和把讨论、轮次、交接合在一起的时间线。冲突不覆盖，可下载草稿再载入最新版本。委派是单独的确认；有计划时委派给当前步骤的 agent。
- 通知：设置页开启本设备的推送（需要 HTTPS；iPhone 需从主屏幕打开），`/sw.js` 只处理推送与点击跳转。
- AI 用量：在「设置 → AI 模型 → 连接」展开「用量与余额」。官方 DeepSeek 和已登录的 Codex 连接支持手动刷新与定时监控。Claude Code 订阅可在 macOS 执行器上开启后台刷新。首次在对应设备运行 `lumio runtime claude-quota-login` 完成官方登录，开启监控后每 15 分钟刷新，也可手动查询。页面仍支持会话状态栏采样。切换 Claude 账号后重新绑定。启用监控并填写阈值后，可在设备的通知设置中接收 AI 用量提醒。
- 知识库：搜索、类型筛选（旧版任务/项目笔记默认不显示）、引用与被引用；私密笔记需要显式打开。可新建论文、视频、网页、想法，保存前完整撰写正文。
  详情页即编辑器（实时预览），停顿约 800 ms 自动保存；冲突时保留草稿并可比较。笔记详情不显示相对路径。
  相关推荐在左侧列表底部，显示命中片段，编辑期间保持稳定高度，空结果不收起、内容在区内滚动；列表和引用候选高亮匹配的标题/正文文字。
  输入 `[[` 或 `【【` 弹出引用候选：Enter 插入链接，Shift+Enter 插入上标脚注。脚注悬停或聚焦时在标号旁显示浮层，点击唯一笔记来源的上标直接打开该笔记，导航前沿用草稿保存保护。
  私密、旧工作笔记和元数据不合法的笔记只读。
- 执行：运行按「需要处理 / 进行中 / 已结束」分组，显示所属任务与执行器名称；报告、等你回答的问题、取消、产物下载（核对大小和 SHA-256）。例行任务的计划、启用/暂停与编辑；设备与引擎。
- 助手：对话历史、流式回复、停止接收；中断后核对已保存状态，不自动重发。显式记忆的保存与遗忘。模型由 Hub 配置，见[助手说明](../../docs/assistant.md)。
- 审批：完整命令参数、所属执行、执行器与理由；核对不到所属执行时不允许批准。

快捷键：⌘K / Ctrl+K 命令面板（跳转、新建、搜索任务/项目/笔记）；1–6 切换模块；C 新建任务；/ 聚焦搜索；J / K 或 ↑ / ↓ 在列表中移动；⌘↵ 提交表单或说明。界面随系统切换明暗主题，窄屏时侧栏变为底部导航，列表与详情分屏显示。

同一次登录中切回聊天、知识库、任务或项目时，会保留所选条目、筛选、输入和滚动位置。助手回复可在切页后继续接收。桌面侧栏可收起为图标栏，聊天和任务讨论可从左侧标记跳转消息，讨论输入框固定在详情底部，知识笔记可按章节跳转。

## 手柄（G1-1～G1-3）

按手柄按钮或拨动摇杆进入手柄模式。焦点框和底部提示条随当前条目更新，提示条最多显示五个可用键。移动或点击鼠标、使用键盘会退出，重新使用手柄时回到上次焦点或同一区域的最近条目。

设置 → 通用 → 手柄可查看连接、按键与摇杆读数，改键或恢复默认。改键保存在本浏览器，占用已有键位时交换两项。非标准映射也可以使用，可按实际按键编号调整。测试模式会暂停界面命令，B 可退出测试。

| Xbox | 操作 |
|---|---|
| 十字键 / 左摇杆 | 移动焦点，按住连发。区域边缘按屏幕方向跨到相邻区域 |
| A | 打开详情或执行当前主要操作 |
| B | 退出输入、关闭菜单与对话框或返回列表 |
| X | 待办上委托，验收、提议和权限申请卡片上拒绝 |
| Y | 打开更多操作 |
| LB / RB | 切换模块，到首尾停住 |
| 右摇杆 | 滚动详情、长文本或对话框 |
| View | 执行当前提示上的按钮，例如撤销或查看执行 |
| Menu | 打开命令面板 |
| RT | 预留给 G1-4 按住说话 |

高权限命令审批、彻底删除、含 full 权限或钩子的计划批准，以及授予 full 权限，需持续按住主要操作键一秒。松开、切走页面、换手柄、切回鼠标或键盘、焦点变化或卡片被刷新时取消。操作仍通过原有按钮与权限检查。普通任务完成可在任务列表中重新打开，提议决定可从审批历史再次查看。

输入框聚焦时，B 退出输入，RT 留给后续语音功能。页面不可见或窗口失焦时停止手柄轮询。多个手柄同时连接时响应最后操作的一个。Today 的 J/K 与方向键也可移动焦点。

## 由 Hub 提供与 App（ADR 0027）

`src/entry.ts` 是给 `apps/cli` 用的入口：`buildWebAssets()` 构建浏览器资源，`webFiles(assets, { apiBase: "" })` 返回页面、JS/CSS、PWA 清单与图标的文件表，`WEB_CSP` 是页面的 CSP。网页由 Hub 在自己的地址上提供，浏览器与 Hub 同源，直接请求 `/v1` 和 `/v2`。发布构建把 JS/CSS 以文本方式嵌入 `lumio`；源码运行时即时构建。

页面带 Web App Manifest 与图标：Safari「文件 → 添加到程序坞」、Chrome「安装」、iPad/iPhone「添加到主屏幕」即可当 App 用。不注册 Service Worker，不缓存业务数据。

## 配置

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `LUMIO_HUB_LISTEN` | `127.0.0.1:7420` | Hub 与网页的监听地址 |
| `LUMIO_PUBLIC_URL` | 空 | Hub 的对外地址（HTTPS 由部署者提供） |
| `LUMIO_WEB_ORIGINS` | 空 | Hub 额外允许的浏览器来源，逗号分隔 |

反向代理直接转发到 Hub，保留 Host；配置 `LUMIO_PUBLIC_URL=https://lumio.example.com` 后同一地址即可访问网页和 API。
额外来源只接受无路径、凭据、查询或片段的 HTTP(S) 来源。Hub 不提供 HTTPS。

## 边界与实现

原生 TypeScript、DOM、CSS，Bun 构建并提供静态资源；没有新增第三方依赖。浏览器与 Bun 服务端分开检查类型，避免 DOM 类型影响后端。

Hub 为页面和资源设置限制性 CSP、DENY、nosniff 和 no-referrer，API 响应禁止缓存。
浏览器请求（带 Origin 或 Sec-Fetch-Site）的 Host 与 Origin（若有）须匹配监听地址、对外地址或额外允许来源。
接口继续按原有令牌鉴权、授权和审计；CLI/执行器请求没有浏览器头时不受来源限制。

登录凭据默认保存在当前标签页的 sessionStorage，可选保存在当前浏览器同源的 localStorage；按网页所在的 Hub 来源隔离。恢复时先验证身份，退出或验证收到 401/403 清除对应凭据并清空页面；临时断线保留凭据并支持重试。刚配对但尚未验证的令牌只在连接页内存保留，可重试验证，不重复消耗配对码。已记住登录的其他标签页会响应退出/账号变化。存储被禁用时明确提示降级。令牌不写入 URL 或日志，业务内容不缓存在浏览器；浏览器凭据对同源脚本可读，保护依赖既有 CSP、安全渲染与设备访问限制。Markdown 转义原始 HTML，只允许安全链接，不加载远程图片；过期请求不能恢复已关闭的私密内容。

目前知识只读，任务关系和资料引用可查看；不提供现有 API 以外的编辑能力。停止助手接收不承诺撤销服务端已经进行的工作，界面会核查持久化记录。

## 开发与验证

```sh
# 在 apps/web 下
bun run build           # 输出浏览器 JS/CSS 到 dist
bun run typecheck       # 服务端与浏览器类型检查
bun test test           # Web 测试

# 提交前，在仓库根目录
bun run check
```

测试覆盖静态资源与 PWA 文件、契约命令、Markdown 安全、文件校验和会话清理。浏览器验收用临时合成 Hub、知识库、模型和执行器，不读取真实 vault 或调用真实 AI。完整证据见 [P4-1](../../docs/tasks/P4-1-web-workbench.md)。

设计依据：[ADR 0026](../../docs/adr/0026-web-workbench.md)、[现行设计](../../docs/DESIGN.md)。
