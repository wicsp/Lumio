# apps/chrome-ext — Lumio 浏览器插件（I1-7，ADR 0057）

在正在看的页面上点一下，就把它存进 Lumio 的 Inbox。插件直接连 Hub，把你看到的内容送过去，Hub 不需要再联网下载。

## 存什么

| 页面 | 插件送给 Hub 的 |
|---|---|
| 普通网页 | 整页 HTML（太大时改送页面文字），由 Hub 抽出正文 |
| YouTube、B 站视频 | 页面已有的字幕（优先人工字幕，其次中文、英文、自动字幕）和简介；取不到字幕时只送简介并标明 |
| arXiv、DOI、PDF 链接 | 只送链接，由 Hub 取全文与元数据 |

右键点链接 →「把链接存到 Lumio」：只存链接，结果在工具栏图标上显示 ✓ 或 !。

## 使用

1. 构建：`bun run --cwd apps/chrome-ext build`，产物在 `apps/chrome-ext/dist/`。
2. Chrome 打开 `chrome://extensions`，开启「开发者模式」，「加载已解压的扩展程序」选 `dist/`。
3. Lumio 中打开「设置 → Hub 与执行器 → 浏览器插件」，点「生成配对码」。
4. 插件设置页填 Hub 地址和配对码，点「连接」。Chrome 会请求访问这个 Hub 地址的权限。
5. 在页面上点工具栏的 Lumio 按钮，或按 `Alt+Shift+S`。弹窗打开即保存，处理完可以直接存档、标为已读或丢弃。

令牌只存在本机插件存储里（`chrome.storage.local`），身份是 human，与 Web 相同；「断开」即删除。

## 结构

- `src/page.ts`：选存法、整理字幕、生成捕获请求（纯函数，有测试）。
- `src/inject.ts`：注入页面运行的函数，必须自成一体（会被序列化）。视频字幕在页面的 MAIN world 读取，用的是你在页面里的登录状态。
- `src/popup.ts`、`src/options.ts`、`src/background.ts`：弹窗、设置页、右键菜单。
- 文案：界面跟随浏览器语言（中文 / 英文）。

## 已知限制

- YouTube 的字幕接口有时需要页面额外的令牌，直接下载会拿到空内容；这时会改读页面上已展开的「显示文字记录」面板。都取不到时只存简介。
- 浏览器里打开的 PDF 读不到内容，只送链接；需要登录才能下载的 PDF 暂不支持。
- 需要 Hub 接受插件来源的请求，并在没有公网地址时也能生成配对码（任务 I1-7a）。
