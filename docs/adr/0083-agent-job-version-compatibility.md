# 0083 普通 Agent 任务接受更新的 CLI 版本

- 状态：Implemented（2026-11-18）
- 领域：执行器、引擎升级兼容、阶段 Git 权限
- 关联：ADR 0005、0049、0069

## 背景

Codex 升级到 0.169.0 后，Hub 和 Runtime 的 0.166.0 精确判断阻断了已获阶段 Git 授权的轮次。三种 CLI 各自发布升级，普通轮次需要允许更新后的版本继续尝试执行。

## 决定

- Codex、Claude Code 和 Pi 的普通轮次保留支持现有 CLI 参数的最低版本，移除版本上限。新版本按现有适配器执行和解析，CLI 或运行失败仍按正常结果报告。
- Hub 检查已登记的阶段能力，Runtime 解析实际 checkout 的 Git 路径。非交互 Codex 使用命名权限配置，最低版本为 0.166.0，并用 `--strict-config` 启动，让不认识配置的 CLI 在执行前报错。只读与工作区写入阶段各自沿用原沙箱，Git 只在已授权的 checkout 元数据路径开放。
- 同轮问答与审批、Codex 原生登录以及 Pi 结构化运行事件沿用各自已验证的版本条件。「已连接的 agent」提示执行器版本与同轮交互验证版本的差异。Job 协议与 Runtime 登记格式保持兼容。
