# 0006 人与 AI 的协作边界：AI 提议，链接由人建立

- 状态：Accepted（P1-4 实现）
- 日期：2026-10-22

## 背景
vault 里的知识价值主要来自"哪些想法、论文、实验之间有关系"。如果 AI 可以随意建立链接，
链接图会很快被大量看似合理、实则未经思考的关系淹没，人也会失去对知识结构的掌控。

## 决定
- AI 可以：生成草稿笔记、摘要、评估；**提议**链接和标签；修改明确标为 AI 产出的内容。
- AI 不可以：直接写入人拥有的链接（正文里的 `[[...]]`、frontmatter 的 `related`），
  也不可以修改人写的正文。
- AI 的提议存放在 **Hub 的提议队列**中，由人在客户端接受或拒绝后，才由 Hub 写入 vault（ADR 0007）。
  AI 生成的内容（总结、评估等）写在笔记正文的 `<!-- lumio:ai … -->` 标记区块里，AI 只能整体重写区块内部
  （格式见 ADR 0012 第 3 节）。
- 这条规则由 Hub 在写入时执行，而不是靠事后 review。
- 接受一个提议后，这条链接就属于人；之后 AI 不得自行删除或改写。

## 后果
- 好处：链接图始终反映人的判断；AI 越多，人对结构的掌控也不会变弱。
- 代价：每条链接都需要人点一次"接受"；以后可以为批量接受提供便捷操作，但不改变归属规则。

## 修订记录
- 2026-10-23：提议的载体由 git 分支 / PR 改为 Hub 的提议队列（随 ADR 0007）（批准：人类）
- 2026-10-23：AI 内容写在 `<!-- lumio:ai -->` 区块中（随 ADR 0012）（批准：人类）
