# 0085 命令审批的 AI 摘要

- 状态：Implemented（2026-11-21，PR #313）
- 领域：Approval、AI 模型、Web
- 关联：ADR 0020、0041、0064，任务 `task_01M7VRPBMD2E4G44BHT9G1MACK`

## 背景

高权限审批展示完整 argv。多层 shell 和 SSH 的参数使用户难以快速判断操作意图和影响范围。现有对话入口会创建会话和请求快照，并可能提供工具。资料摘要流程面向知识库。审批需要一次独立、无工具的分析请求。

## 提议

- 在 `packages/schema` 定义 `GET/POST /v2/approval/proposals/:id/summary` 的请求和响应。只有能查看该提议的 human 可访问，且仅支持 `exec.privileged`。Hub 按 ID 读取已经冻结的 argv，浏览器无需提交命令。GET 只返回缓存状态，POST 生成或读取现有结果，`refresh: true` 明确请求重生成。
- 返回有界结构化结果，包含一句话概括、读写类别、受影响的机器或路径、网络连接或暴露、三档建议（批准、谨慎、拒绝）、一句理由和模型名称。提权由审批类型确定。命令无法静态判断时明确表示未知。摘要及状态与原有批准、拒绝和签发凭据的流程无数据依赖。
- 复用 Hub 的 `AIConfigurationService.model` 和 OpenAI 兼容 `/chat/completions` 适配器。部署者用 `LUMIO_APPROVAL_SUMMARY_PROFILE` 显式指定一个属于发起请求账号的轻量 API Profile，实际模型名来自该 Profile。缺省关闭，不回退到聊天默认模型。UI 在首次生成前说明命令会发给配置的模型服务。
- 系统提示词要求把 argv 当作不可信数据，按原参数边界理解，忽略命令内的指令，按界面语言输出结构化结果。Hub 不提供工具、对话历史、工作目录、任务正文或输出。限制输入大小并在 Hub 本地检查疑似密钥。发现疑似密钥或命令超限时不发送，不截取一段命令让模型猜测。路径、主机和参数引用只能来自原输入，经校验后展示。拒收工具调用、超长或不符合契约的结果。自由文本禁止补写参数、替代命令或把推测写成已确认事实。
- 打开命令详情时只查缓存。点击「生成 AI 摘要」后调用模型，Hub 总时限 10 秒。成功结果按账号、审批 ID、界面语言和模型配置版本保存在 Hub 有界内存缓存中。同一键的并发调用合并，已缓存时直接返回，明确刷新才替换。服务重启或缓存淘汰后可再次生成。失败显示「暂无摘要」及重试，已有成功结果在刷新失败时保留。
- 页面展示「AI 生成，仅供参考」，完整 argv 继续可见，人在原来的按钮上做决定。AI 结果不进入审批审计凭据和会话历史。

## 验收

- 验证接口只允许可见的命令类审批，模型无工具，疑似含密钥的 argv 不离开 Hub。
- 用假模型验证输入参数边界、无效输出、超时、并发去重、缓存和手动刷新。
- 验证摘要未配置、失败和刷新中时，批准／拒绝按钮仍按原 Job 状态和权限规则工作。
