# 0074 语音想法与讨论

- 状态：Accepted（2026-11-18，人类已授权直接接受并部署）
- 日期：2026-11-18
- 领域：知识编辑、捕获、助手与 HTTP 契约
- 关联：ADR 0034、0051、0059、0066；I1-6

## 决定

- Idea 创建请求允许省略标题。有正文时 Hub 从首个非空行生成临时标题，使用稳定 ID 区分同名的自动标题。手写标题和既有笔记沿用原有规则。空白 Idea 编辑器提供自由正文。
- Mac 长按完成语音识别后，使用现有主对话聊天请求并显式携带 `record_idea: true` 与 `glance`。所见按原有权限绑定到消息。Hub 以用户身份保存独立 Idea，保留原话、所选或所指文字、可确认的来源和本轮消息。用聊天轮次 ID 复用知识创建回执。保存成功后 `AssistantTurn.idea` 与 NDJSON `idea_saved` 事件返回 Idea ID。
- 助手在保存后判断是否回答。语音记录轮只提供读取能力。用户可在普通对话里继续讨论或明确安排工作。Idea 关联原讨论；由助手按 Idea 及当前对话所有者权限读取有限的相关讨论，旧讨论中的私密读取不回放。
- 语义索引是可重建缓存。沿用批准过的向量用途以及全文和向量融合规则，向量请求只发送现有知识检索可见的非私密笔记。百炼连接可创建向量 Profile，只有显式绑定才会向服务发送非私密知识。模型未配置或不可用时继续提供全文检索。

## 兼容性

- 可选字段缺省保持既有客户端的聊天和创建行为。旧 Idea 与对话读入时无需迁移。自动生成的笔记可以用现有知识编辑和回收站功能管理。
