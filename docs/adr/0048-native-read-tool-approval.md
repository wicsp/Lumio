# 0048 原生 Codex 助手的只读工具审批

- 状态：Proposed
- 日期：2026-11-09
- 接续：ADR 0042 的原生会话与工具边界

## 问题

2026-11-09 的一段原生 Codex 对话出现 13 次 Lumio MCP 审批，包括查询任务、项目与执行情况。Hub 已按 agent 身份检查这些查询。Codex 每次额外暂停等待人工点击，打断了同一条查询请求。

## 提议

- 只有会话绑定的 Lumio MCP 中，能力目录明确归类为 `read` 且本会话启用的工具，可以在 Codex 层免逐次确认。优先使用官方每工具审批配置，按能力目录生成精确名单。未知工具和其余工具保留人工审批。
- Hub 继续用对应会话的 agent 身份检查活跃轮次、工具范围、私密边界、参数和访问权限，保留审计与回执。委派、计划提议、命令与文件审批沿用现有边界。
- 只在固定版本验证有效后启用。用合成 Hub 和官方 app-server 测试多次只读调用不弹窗、写入仍提示、越权读取被拒绝，以及恢复会话时按完整配置生效。不能证明按工具收敛时，继续保留现有审批。

参考：[OpenAI 官方 MCP 配置](https://learn.chatgpt.com/docs/extend/mcp#other-configuration-options)。
