# 0075 iPhone 快捷指令语言

- 状态：Implemented（2026-11-18）
- 批准：2026-11-18，人类授权直接接受所需 ADR、合并并部署。
- 日期：2026-11-18
- 领域：iPhone 配对、界面语言与听写
- 关联：ADR 0028、0066

## 决定

- iPhone 配对链接的 JSON 载荷由 `IPhoneShortcutPairing` 契约描述，在地址和一次性配对码之外允许携带 `language`（`zh-CN` 或 `en-US`）。Web 从生成链接时所选的 Lumio 界面语言决定该值。
- 快捷指令与地址和令牌一起保存语言。后续两条指令使用同一配置，听写的 `WFSpeechLanguage` 和 Hub 请求的 `Accept-Language` 都显式采用该语言，运行中的提示采用同一语言。
- 语言沿用配对时的选择。Web 的语言按浏览器保存，变更后重新配对同步手机。旧配对载荷和既有配置缺少语言时沿用中文，避免英文手机上的中文听写再次回退到系统默认。
- 此变更不修改 Hub 配对 HTTP 请求和响应，不迁移既有业务数据。两条签名下载同步更新，避免扫码仍运行旧版收藏指令而丢失语言。
