# 0078 语音助手同轮建单与讨论来源

- 状态：Accepted（2026-11-18，人类明确要求实施）
- 领域：助手工具授权、捕获、任务来源
- 关联：ADR 0029、0032、0059、0066、0074、0076

## 决定

- 语音捕获是同一个主对话的输入。保存原话 Idea 后提供普通前台工具，显式请求建单可直接完成，要求代理执行可同轮提交委派提议。按照既有 agent 权限执行，使用原有批准入口，只有用户批准后创建 Job。单纯记想法仍可静默。所见、历史和引用内容只能补充语境，用户本轮自己的请求才授权操作。
- 对话建单时，Hub 用既有任务知识引用记录关系，并在描述中放可打开的来源链接。语音复用已保存的 Idea。普通聊天可显式保存讨论，或在建单时自动生成 Idea。保留原话、有限的近期相关问答摘录及原消息链接，复用本轮创建回执。已有话题时只取连续同话题的历史，无话题锚点时最多取紧邻的一次无锚点问答。私密读取涉及的对话内容不复制进 Idea。
- 聊天和捕获的 HTTP 请求、事件、任务字段与权限表沿用现行契约。无需回填既有任务或想法。
