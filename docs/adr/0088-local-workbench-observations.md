# 0088 工作台使用观察保存在浏览器

- 状态：Implemented
- 日期：2026-11-27
- 领域：Web、浏览器存储与隐私

## 背景

工作台重构需要从自然使用中观察找资料、回复问题、验收和追问的路径。用户只正常工作，后续再分析。Hub 审计用于追溯业务写入，不能解释页面导航、核查来源或浏览器内的草稿操作。

## 决定

Web 在已验证的 human 会话里自动记录白名单内的页面和语义动作。每个浏览器按 Hub 与已验证凭据的哈希隔离 IndexedDB。每个作用域保留最近 5,000 条，插入、淘汰和暂停判断在同一读写事务内。独立记录当前标签页会话和访问序号，可离线串联该标签页内的事件。记录失败不得阻止业务操作。

事件包含 ISO 时间、所在页面、动作、结果、进入该页后的耗时。个人页、设置页和回收站排除；不保留标题、正文、查询、按键、URL、对象 ID、用户身份或凭据。用户可以在设置的数据分类暂停、恢复、清空或主动导出当前范围。版本 1 的 JSON 导出只用于分析。记录不发送到 Hub，不参与业务同步与备份，不作为授权、完成或人工认可的证据。

## 取舍

复用服务端审计会混淆用户尝试与服务端确认，也会引入收集浏览行为的服务器接口。本次保留浏览器局部视角；不同浏览器的记录需分别导出，清理站点存储、换配对凭据或隐私浏览会影响可取得的历史。后续若要跨设备集中收集，另议接收协议、所有者权限、保留期限与删除语义。
