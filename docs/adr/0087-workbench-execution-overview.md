# 0087 今日页和侧栏读取有界的运行摘要

- 状态：Accepted（2026-11-25，人类批准）
- 日期：2026-11-25
- 领域：Execution、Work、Hub、Web、HTTP 契约
- 关联：ADR 0025、0032、0069

## 背景

工作台每次打开和定时刷新都读取完整 Job 历史，以计算侧栏计数、生成最多五条活动并找出待处理的独立运行。完整 Job 包含执行输入和结果。只取最近若干条会漏掉很早启动的长任务、当前交接中的验收，以及仍待处理的独立运行。分别读取六种状态仍会搬运每条历史失败的完整结果。

## 决定

新增仅供已验证 human 使用的只读接口 `GET /v2/execution/overview`。请求和响应在 `packages/schema` 定义，API Client 提供类型化方法。Web 的 Today 和侧栏共用一次读取。首次显示及定时刷新只读首页。执行历史、单条运行详情、已有交接和审批接口继续提供原有行为。

- `activity` 最多五条，按当前规则先取活跃运行，再按创建时间从新到旧，相同时间按 Job ID 确定顺序。任务只取当前交接轮次或并行分支，同一任务取一条；无任务的独立和 Routine 运行各算一条。缺少可见任务记录时保留其活跃运行。每条只带导航和展示所需的 ID、状态、创建时间、来源（任务及轮次或 Routine）、引擎或命令的简短名称。
- `activity_live_count` 统计上述活动分组后仍活跃的完整组数。`execution_count` 统计侧栏对应的全量 Job 数，含 queued / assigned / running、需要人处理的当前工作轮次，以及独立或 Routine 的 waiting_for_human / failed / unknown；同一 Job 只计一次。两个计数独立于页面行数。
- `standalone_attention` 包含全量条数、当前页条目和可选的后续游标。首页及后续每页最多 20 条，按创建时间、Job ID 倒序，用稳定且排他的游标翻页。Web 展示完整数量，允许继续查看旧项。每条只返回运行摘要及最多 240 个 Unicode 码点的问题或错误预览，详情沿用单 Job 接口。已有 Work 提醒和同轮交互继续由各自的接口给出，以免重复展示。
- Hub 在同一次读快照里组装计数和首页，从 Work 的公开读取接口获取当前交接事实，通过 Execution 存储端口查询计数及有界行。存储查询在 SQLite 中筛选、排序、投影并限量。可使用派生索引，保留现有 Job 存储格式，无需重写历史记录。请求路径不在应用内解析每个历史 Job，不读取日志文件或拼装完整提示词、结果报告。
- 同源 Web 随 Hub 一起分发。旧客户端继续使用原接口；摘要读取失败时，Today 显示该区块的错误，其他区块照常工作。

## 验收

用合成数据覆盖近期列表之外的长任务、旧的独立失败/等待、已处理的历史任务轮次、已完成但仍待验收的当前轮次、同一任务的并行分支、同刻创建的翻页边界。核对计数与旧分类规则一致，响应大小不随完整报告或已完成的历史数量增长。验证 agent 与 runtime 无权读取，原有历史与详情查询照常返回。
