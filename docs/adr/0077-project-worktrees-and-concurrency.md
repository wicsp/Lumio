# 0077 项目工作区与任务并发

- 状态：Implemented（2026-11-18，人类批准后实施）
- 领域：Work、Execution、Runtime、Git 权限
- 关联：ADR 0033、0049、0068、0072

## 背景

同一 Runtime 可以执行多个 Job。不同 Codex session 仍可能指向同一个 checkout，在同一批文件与 Git index 上工作。用户希望项目可以启用自动 worktree，控制项目任务的实际执行并发，并在设置中管理每台 Runtime 的并发。

## 提议

### 项目配置与派发

- 项目保存两项可选配置，提议命名为 `auto_worktree` 和 `max_concurrent`。缺省分别为关闭和 1。并发上限为正整数。CLI 与 Web 支持创建、读取和修改。旧项目按缺省解释，已有配置缺失时无需预先回填。自动 worktree 要求项目在目标 Runtime 上配置 Git 仓库根目录和明确的基线引用，Lumio 项目使用 `origin/main`。
- 并发上限按项目 ID 计算，覆盖同项目的 Runtime 合计，并受每台 Runtime 自己的并发上限约束。未关联项目的 Job 继续走原有流程。Hub 在交付前事务性占用名额，重复同步及断线重连复用原占用。有效执行结束后释放名额。执行状态无法确认时保留占用，直到既有恢复流程确认该 Job 已停止。降低上限允许已入场任务结束，新任务等待。
- 等待名额的 Job 保留既有队列状态，记录派发输入。同一项目内优先交付最早且可执行的 Job，其他项目仍可继续派发。既有任务权限、审批及阶段交接规则继续适用。项目并发配置更新后用于后续入场判断。

### Runtime 并发设置

- 在 Web「设置 → Hub 与执行器」中，用户可以按执行器设置或清除 Job 并发上限。Hub 按 Runtime ID 保存期望值，仅 human 可写。设置正整数时覆盖该设备的本机值，清除后回到本机 `LUMIO_RUNTIME_MAX_CONCURRENT`，本机未配置时默认为 1。
- 设置页同时显示期望值、Runtime 已确认的生效值与待生效状态。支持此能力的 Runtime 在下一次同步时收到配置，更新本地调度并回报生效值，无需重启。离线时可保存设置，重新连接后应用。降限让已运行的 Job 自然结束，释放足够名额后才启动新 Job。
- Runtime 并发设置只控制现有 Job 调度槽，与项目并发上限同时生效。通过显式能力协商兼容旧 Runtime，设置页对不支持的设备显示当前值及升级要求。

### Runtime 工作区

- 自动 worktree 适用于已启用项目的开发轮次。Hub 在派发快照中明确传递工作区要求。Runtime 在 Agent 启动前，从配置的已提交基线创建受管理的 Git worktree 和唯一分支，按项目和任务标识记录归属、仓库、Runtime、路径、分支和基线提交。明确指定的 task workdir 与自动配置冲突时显式报错，避免在意外目录执行。
- 同一任务的续跑与返工复用原工作区和分支，包括尚未提交的内容。同一工作区同时最多一轮可写。绑定工作区不可用、目标 Runtime 变化或项目仓库配置变化时，将原因交回人处理，避免自动创建空目录或误用旧目录。初版保留工作区和分支供续跑、查验和交接，回收机制另行设计。
- Runtime 只操作授权的项目仓库与自管目录。它负责校验仓库根及工作区归属、串行创建同一仓库的 worktree，并以可恢复方式处理同一任务的重复准备。Agent 以已创建的 worktree 为工作目录启动，Git 写入仍受原有阶段权限限制。Git refs、端口、数据目录与部署仍遵循各自的并发约束。
- 自动 worktree 的 Job 仅交付给明确声明支持的 Runtime。采用协商后的可选扩展，并覆盖旧 Hub、旧 Runtime 和既有任务的升级行为。所需字段和测试以 `packages/schema` 为准。实施时同步更新 Work、Execution 和 Web 设计分册。

## 验收

- 项目默认串行，调到 2 后跨 Runtime 最多同时交付两个项目 Job，第三个等名额释放。覆盖重复交付、重启、取消和降低上限。
- 同仓库的两个独立任务获得不同路径与分支，原 checkout 的未提交内容不进入新目录。同一任务从首次执行到续跑、返工使用同一个路径与分支。
- 覆盖旧 Runtime、工作区丢失和配置冲突，避免误入主 checkout。使用合成 Git 仓库与隔离 Runtime 验证。
- 在设置中把支持的 Runtime 从 1 调到 2，无重启启动第二轮；降回 1 不打断当前执行。覆盖恢复本机值、离线后同步与旧 Runtime 能力提示。
