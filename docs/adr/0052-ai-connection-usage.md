# ADR 0052：AI 连接的余额与订阅额度

- 状态：Proposed
- 日期：2026-11-10

## 背景

设置页的 Connection 已能说明凭据来源和所在设备。用户需要在同一处查看 DeepSeek 官方 API 的可用余额、Codex 订阅的额度窗口，以及 Claude Code 订阅的最近一次采样。三者的计量单位、账户归属与采集方式各自独立。现行连接配置和原生会话契约没有账户级用量接口，也没有 Claude Code 状态栏采样绑定。

## 决定

### 1. 连接与读取契约

- 以 Connection 为展示和授权单位。Hub 新增仅连接所有者可访问的用量读取、刷新和提醒设置接口，沿用 `/v2/ai` 的 human 授权。公开配置、Profile 和原生对话的现有响应保持兼容。用量接口不进入 agent 能力目录。
- 用量快照按来源区分 API 金额与订阅窗口。金额用原币种和十进制字符串，保留币种、可用、充值与赠送余额，以及供应商返回的 API 可用状态。窗口记录额度标识、来源提供的名称或窗口长度、已用百分比与重置时间。缺失字段保持未知。UI 用同一套「剩余」口径展示百分比和进度条。
- 每个来源独立报告最近成功采集时间及当前采集状态，区分等待首份快照、来源不可用、未登录、Runtime 离线、采集失败与过期。刷新失败可展示仍归属于当前连接的旧快照及其时间。已过重置时间的窗口在收到新数据前保持过期状态。支持情况和状态使用可翻译的枚举，不返回供应商原始错误。
- 新增 Runtime 绑定的 `claude-code-subscription` 连接种类，仅供用量采样。它使用现有 Claude Code 登录，不接受 API Key 或自定义地址，也不作为 Profile 的引擎来源。已有 Claude Code Job 能力保持独立。

### 2. 采集和身份边界

- **DeepSeek**：Hub 仅为明确配置为 DeepSeek 官方 HTTPS 来源的连接，用该连接已保存的密钥向固定地址 `https://api.deepseek.com/user/balance` 发起请求。拒绝重定向；自定义兼容端点显示余额查询不受支持。按币种展示，不换汇。 [DeepSeek API](https://api-docs.deepseek.com/api/get-user-balance/)
- **Codex**：通过连接绑定的 Runtime 和已有连接级 App Server，调用 `account/rateLimits/read`。查询无需打开对话或发送模型请求。支持多个额度桶和窗口，旧版单桶响应作为兼容输入；缺失字段由界面说明。报告绑定连接、Runtime 身份和已验证的登录代次。Hub 只接收绑定设备的报告。 [OpenAI Docs](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)
- **Claude Code**：由人选择 Runtime，并为使用目标订阅登录的交互式 Claude Code 会话显式启用 Lumio 提供的状态栏采样命令。提供会话级配置示例，不自动改写全局或项目设置。采样命令只从标准输入提取 `rate_limits.five_hour` 和 `rate_limits.seven_day` 的百分比及重置时间，在 Runtime 私有状态目录原子保存规范化快照。Runtime 用自己的认证通道上报绑定的连接和采样代次，采样命令本身无需 Hub 或供应商凭据。状态栏没有可验证的订阅账户标识，因此界面标为设备会话采样，换登录时由人重新绑定。重新绑定作废旧代次及快照；未产生有效读数时显示等待采样。重复的状态栏载荷、空载荷和打开页面都不能把旧读数标成刚更新。已有状态栏的用户可显式组合命令。 [Claude Code 状态栏](https://code.claude.com/docs/en/statusline#available-data)
- 仅传输与保存规范化读数、来源和绑定标识，不采集会话正文、完整状态栏 JSON、供应商令牌或本地账户配置。与用量相关的 Runtime 能力显式协商。旧 Runtime 继续运行原有工作，旧 Hub 不接收新能力的上报。

### 3. 快照和提醒

- Hub 在私有业务库按所有者、连接和当前采集绑定保存最后一次成功快照及提醒状态。并发刷新合并，晚到的旧采样不能覆盖较新采样。密钥、来源、设备、登录或采样绑定更换时使旧快照和告警状态失效；单纯改名不使数据失效。连接删除时移除其用量记录。
- 页面打开先读快照，并允许手动刷新 DeepSeek 与 Codex。启用监控的 DeepSeek 与在线 Codex 连接默认每 15 分钟尝试查询，失败退避。Claude Code 仅在有效的新状态栏采样到达后更新。
- 提醒由所有者启用。余额阈值按币种设置，订阅阈值按剩余百分比设置。由有效新读数进入阈值区间时通过现有通知系统提醒一次，按连接及币种或额度窗口去重。恢复后再次越线或在新窗口越线可再次提醒。通知状态持久化，过期读数和采集错误不触发低额度提醒。第一版保留最近快照。

## 验收

- 用合成响应验证三种来源的解析、授权和旧版本兼容，覆盖多币种、多窗口、缺失字段、断线、重置和采样过期。
- 验证密钥只发送到固定官方端点，非所有者及错误 Runtime 被拒绝，换绑、晚到上报和重复状态栏数据不会泄漏或刷新旧快照。
- 验证重复刷新与重启后的提醒去重。Web 在既有 AI 连接页按连接展示快照、更新时间、明细和可用动作，Claude Code 在首份读数前提供设置指引。
