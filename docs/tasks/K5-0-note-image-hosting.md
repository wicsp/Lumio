# K5-0 笔记图床

- 状态：[ADR 0073](../adr/0073-builtin-note-image-hosting.md) 已实现，待合入及真实图床验收。
- 必读：`docs/DESIGN.md`、`docs/design/knowledge.md`、`docs/design/hub.md`、`docs/design/web.md`、`docs/design/security.md`。
- 用户要求：现有 uPic + R2 可迁入 Lumio，内置且轻量，覆盖主流图床，作为一项完整功能交付。

## 交付内容

1. 设置中配置预览域名、禁用上传或配置一个图床。提供 S3 兼容入口、GitHub 和自定义 HTTP，以及 ADR 所列的厂商预设与自建图床示例。密钥控件不回显。保存时提示图片会发往哪个服务、预览会请求哪些域名。
2. 公开知识笔记支持在编辑器选择、粘贴或拖入图片。上传成功后插入 Markdown，保存后重开能预览。uPic 已有的 Markdown 图片在配置同一交付域名后直接显示。
3. 提供 R2 的 endpoint、桶、region `auto`、前缀、图片交付域名及桶级凭据设置说明。用户在本机填写凭据，现有对象无需迁移。交付版本继续用仓库编译和部署流程。

## 验收

- Schema 测试覆盖每个目的地分支、版本与输出、非法网址和超限字段；核对生成物。
- Hub 契约测试用合成 PNG、隔离笔记和模拟端点，校验上传字节、MIME、对象键、S3 路径与签名范围、GitHub 请求、HTTP 原始及 multipart 请求和 URL 提取。验证权限、大小、伪造类型、跳转、响应超限、请求超时、设置并发、重启保留、换目标与清除凭据，以及无泄漏的错误和审计。
- 浏览器测试覆盖选文件、粘贴与拖放、光标变化、切换笔记或登出、上传失败、自动保存、重新打开和现有 uPic 链接。核对 CSP 只放行配置的 HTTPS 来源，未允许的地址只显示替代文字。用合成 vault，不访问日常实例的数据。
- 运行 `bun run check` 及单文件构建。真实联调用专用测试桶，确认上传后用图片交付地址读回；注明哪些厂商只通过模拟验证。接入用户已有 R2 桶时由用户通过设置填写凭据。

## 实施记录

- 预研已用 Bun 1.4.4 单文件程序验证 R2 `PUT` 预签名的 endpoint、bucket、对象路径和 `auto` 签名范围。实际写入与交付域名读回待测试桶验证。

- Hub 契约测试通过，验证权限、持久化、版本冲突、CSP、凭据脱敏、图片校验、S3 签名请求、GitHub、multipart HTTP 和原始 PUT。HTTP 传输使用内置 HTTPS 请求，连接到已校验的 DNS 结果。
- 合成 HTTPS 端点确认实际签名上传、按交付地址读回、拒绝转发和拒绝超大上游响应。尚未使用供应商真实账号验证。
- 合成 Web 浏览器验收通过：配置 R2、刷新预览策略、选择、粘贴、拖放、自动保存及重开。覆盖在现有图片行上拖放时保留原 Markdown 链接的回归。
