状态：实现完成，已安装本地试用；人工试用通过后提交实现 PR。

## 使用流程

1. 在知识库打开公开笔记，直接编辑标题、正文；停顿约 800 ms 后自动保存，⌘/Ctrl+S 立即保存。
2. 新建仍可选论文、视频、网页、想法，在同一详情页填写字段和正文；首次创建后进入自动保存。
3. 左侧「相关笔记」随段落变化，最多 5 篇，默认 3 篇；每篇附实际命中段落。窄屏通过「相关笔记」按钮打开列表。
4. 输入 `[[` 使用当前段落的候选；继续输入文字则搜索标题、文件名/citekey 和正文。上下键选择，Enter 插入文字链接，Shift+Enter 或「插入上标引用」插入脚注。
5. 上标按首次出现编号，文末列出来源；悬停、键盘聚焦或点击查看内容，链接可打开来源。手写脚注保留，未使用定义可明确删除。
6. 检测到外部修改时暂停保存并保留草稿；点击「对比已保存版本」，把需要的修改合并进草稿，再点击「已完成合并，恢复保存」。

## 实现与边界

- 契约：新增 document/update/related/references 严格请求与响应；只允许 human，未扩展 agent 工具或 runtime 权限。
- Knowledge：保留未知 YAML 字段、注释和原始正文；词法排序、中文分词、有限候选的英文拼写近似；安全链接与同名路径消歧。
- Storage：整文件 SHA-256 revision、不可变请求快照、发布前回执和字节备份、原子写入、删除/移动/外部修改检查、索引和审计恢复。
- Hub：共享写入互斥、敏感内容检查、Git 与审计；为每次 HTML 响应生成样式 nonce，不添加 unsafe-inline 或 unsafe-eval。
- API Client：新增四个经过契约校验的方法。
- Web：同页 CodeMirror 实时预览、保存队列、草稿保护、相关推荐、引用补全、Markdown 脚注与编号视图。未支持的复杂 Markdown 保留源码，不做 HTML 往返转换。
- 类型、ID、路径、citekey 不随标题变化；无 ID、非法元数据、私密和旧工作笔记保持只读。PDF 标注、RAG、协作编辑和稳定段落锚点不在本期。

外部编辑器不共享 Hub 的锁。发布前后检查与预保存字节提供冲突检测和恢复，但最后一次检查至原子替换之间仍不是跨编辑器事务；不声称消除所有文件系统竞态。
候选召回每路最多 120 条、每篇最多比较 2000 段；索引仍沿用既有增量扫描，大规模真实库的性能尚需后续实际使用评估。

## 依赖与构建体积

仅 Web 新增六个已批准的直接依赖：`@codemirror/state`、`@codemirror/view`、`@codemirror/commands`、`@codemirror/language`、`@codemirror/lang-markdown`、`@codemirror/autocomplete`。
理由：成熟的选择、撤销、IME 和补全内核，原始 Markdown 无损保留。textarea 加预览无法满足同页编辑；自写 contenteditable 和富文本往返成本与风险更高。
Bun 1.3.13 生成锁文件。以 `60494af` 为基线，压缩 JS 从 684,838 B 增至约 1,246,912 B；gzip 从 186,893 B 增至约 382,868 B（增加约 191 KiB）。
