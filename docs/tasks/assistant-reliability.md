# 前台助手可靠性：第一至五阶段

人类已要求实现、测试并部署前三阶段，随后在 7420 试用。必读 `docs/DESIGN.md`、`docs/design/assistant.md`、`docs/design/web.md`、`docs/design/security.md`。按 app/package 分 PR；不改 Schema、存储格式或权限模型，不新增依赖。

## 第一阶段：页面焦点

`apps/web` 以任务／项目面板实际加载的对象生成焦点，包含模块、对象 ID、保存后的标题和 revision。上下文标签和聊天请求使用同一来源，不依赖 `replaceState` 后未更新的路由缓存。加载、关闭、失败时清掉旧焦点；晚返回的响应不得覆盖新选择。固定上下文继续指向固定对象，关闭共享不因同一对象的后台刷新而复位。消息在点击发送时固定焦点。

验收：列表打开任务 A → 手动点 B → 问“当前任务是什么”，请求必须是 B；AI 打开 A 后再点 B 同样成立。项目同测。覆盖快速切换、失败、关闭、固定／关闭共享、后台刷新和连接尚未就绪时发送的边界。

## 第二阶段：工具与实时能力

`packages/assistant` 不按澄清状态或话题锚点裁减工具。模型能先查找、再判断是否需要追问；信息足够时直接使用现有工具。每次请求注入当前 UTC 时间和实际工具清单，旧对话里的能力声明不能覆盖当前事实。UTC 时钟不代表用户时区；本阶段不新增浏览器时区契约。

验收：没有锚点且请求含指代词时，读取和写入工具仍全部存在；模型可以连续查找并修改，也可以只追问。授权、提议、取消、未知结果和幂等规则继续由原有执行入口处理。

## 第三阶段：历史保留

`packages/assistant` 在原有 20 KiB 历史预算内优先保留最近三轮，再补最多四轮同话题历史。先为候选轮次保留紧凑事实，再用余量装入完整交互，避免长工具结果或历史续接信息让最近整轮消失。

紧凑事实包含原话摘录、回复摘录、工具状态统计、有限的实际调用参数／结果摘录及其来源消息 ID，明确截断和省略。不把模型回复当作操作成功证据；失败、取消、未知结果保持原状态。当前轮次的调用／结果对和供应商续接保持完整。历史私密读取不回放，来源可见性逐次重查。

验收：长读取成功后继续追问仍能找到原问题和成功的工具记录；失败或未知写操作不伪装成功或自动重放；多字节文本和大续接状态不挤掉最近轮次；模型请求没有孤立的工具消息；撤销可见性后澄清路径也不带回旧内容。

## 验证与部署

- 合成测试：`apps/web/test/browser/work-focus.test.ts`、`packages/assistant/test/`；同时运行既有 Storage/Assistant 和 Hub 集成测试。
- 每个改动合入前通过 `bun run check`；测试不读取或写入真实 vault。
- 合入后使用 `bun run scripts/deploy-local.ts` 从最新主线构建和部署，核验 7420 的健康、网页静态资源和 Runtime 心跳，并跟踪主线 CI。
- 试用时刷新页面；分别测试手动换任务、AI 打开后换任务、澄清后继续执行、长结果后的追问。

## 第四阶段：话题恢复与页面变化

人类试用前三阶段后要求继续实现并部署。助手必须区分当前页面、讨论主题、历史页面和已经发出的展示请求。焦点变化只表明两次发送时观察不同，不能因此编造“之前看错了”，也不能认定导航成功或失败。

从旧锚点、成功读过／打开过的对象和正文中的稳定引用构建至多 16 个、12 KiB 的候选目录，带来源消息范围、讨论时间及原话摘录。旧记录的页面锚点即使不准确，也能按实际读过的对象恢复。原话文字匹配只排序，最终话题由模型结合请求选择；信息不足时沿用现有搜索／读取工具。来源不可见或私密读取的历史不回放。

模型通过现有导航工具选中对象，导航请求成功后更新同轮后续消息的锚点，并立即补入相应历史；重启后沿用最新消息锚点，不修改原聊天正文或数据库格式。测试覆盖跨二十轮恢复、服务重启、页面来回切换、无权限来源和导航失败。

## 第五阶段：随聊天主动展示

模型识别出具体笔记、文章、任务或项目后，主动用现有展示工具打开并讨论，不等第二次“打开”指令。相关材料在面板列出；多个候选不确定时先展示供选择。回答“我现在看什么”使用当前焦点，不重复历史导航。一个轮次内的焦点是发送时快照，不因尚未观察到新页面而反复导航。

浏览器把发送时刻传给本地导航策略：发消息前的点击不阻止本轮展示；发消息后人又切页、操作或编辑，或标签页失焦时保留当前位置和“带我过去”入口。成功切换主对象后清掉旧的相关面板，避免跨主题残留；不同展示请求的异步读取不能互相覆盖。

验收：从任务列表说“继续刚刚那个教育话题”时恢复教育笔记上下文并请求打开；提到另一篇文章时查找、展示并继续讨论；在回复期间手动换任务，不被迟到的导航抢回；明确要求保持当前页时只讨论／显示相关卡片。现有能力目录未授予的操作不因本次改进新增权限。
