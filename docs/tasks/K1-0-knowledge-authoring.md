# K1-0 知识新建入口与正文输入

状态：实现完成，本地试用中；人类试用通过后再提交实现 PR。
设计：ADR 0034 第 1–5 节，2026-11-06 人类批准；设计 PR #98 已合并。

## 交付

- 知识页与命令面板均可新建论文、视频、网页、想法。
- 按类型提供字段、正文模板、Markdown 输入与预览；论文支持 arXiv/DOI 导入及失败后手填。
- 导入只补空字段；切换类型保留各自草稿；关闭未保存内容有确认。
- 保存不确定时保留原请求，关闭再打开仍可重试；正文只读但可以选中复制。显式确认后可作为新的一次保存继续编辑。
- 保存后直接阅读、搜索；资料阅读页显示类型、作者/平台及安全的来源链接。
- 已保存笔记的编辑、PDF 附件/标注不在本期范围内。

## 模块与契约

| 切片 | 修改范围 |
|---|---|
| K1-1 | `packages/schema`：四类创建、模板、论文解析严格输入输出；实体格式不变 |
| K1-2 | `packages/knowledge`：模板结构、文件名/citekey/元数据与正文生成；`packages/storage`：创建回执与安全文件发布 |
| K1-3 | `apps/hub`：仅 human 可用的 HTTP 接口、受限论文来源抓取、索引/审计/Git；`packages/api-client`：对应方法 |
| K1-4 | `apps/web`：入口、字段、正文、预览、草稿与恢复状态 |

接口：GET `/v2/knowledge/templates`，POST `/v2/knowledge/papers/resolve`、`/v2/knowledge/notes`。
新增契约属于已批准 ADR 的连带修改；没有新增依赖。Claude 起草契约和页面，Codex 按批准范围审阅修正、实现与联调；Claude 完成交叉审阅。
JSON Schema 已通过生成脚本导出，生成目录按仓库约定不入库。

`knowledge_creations` 在 `hub.sqlite` 中保留请求摘要、分配结果与预期字节；Markdown 是知识权威。
预分配未发布的笔记可沿同请求恢复；已发布文件被修改时明确冲突，删除时保留失败回执并释放路径预留，旧请求不会复活它。
相同请求不同内容冲突，普通同名文件不覆盖，论文保留 DOI/arXiv 去重与 citekey 后缀规则。
模板翻译由应用文案表注入，结构和版本由 Knowledge 拥有。

## 本地人工试用

试用版本：`0.2.1-dev.notes.20261106`。更新前已备份原程序与业务数据；旧 Obsidian 测试内容清理有独立可恢复备份。
真实数据清理由人类单独明确授权，不作为测试数据，也不提交到代码仓库。

1. 刷新已有 Lumio 页面，进入「知识库 → 新建笔记」，或用 ⌘K 查找「新建笔记」。
2. 先选视频，填标题与链接，写正文、预览、保存，再尝试搜索。
3. 试用论文导入和手填、网页与想法；确认字段及模板适合日常使用。
4. 人类确认通过后再创建实现 PR。待本功能 PR 合并时，按 ADR 生命周期将对应小节标记为已实现。
