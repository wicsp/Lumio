# G1-0 用手柄操作 Lumio

依据：无新 ADR（纯 Web 输入方式，不改契约与权限，按 ADR 0036 只写任务说明）；规则改动见 `docs/design/web.md`「手柄」一条。
按住说话依赖 [ADR 0055](../adr/0055-speech-input-and-output.md) 与 [S1-0](S1-0-speech.md)。
必读：`docs/DESIGN.md`、`docs/design/web.md`、`apps/web/README.md`。

## 目标

躺在沙发上只用手柄处理 Lumio 里最常见的决定：在 Today 和任务列表里移动、完成、委托，处理「需要你处理」的提问、验收与批准，按住一个键说话。

## 原则

- **手柄只是另一种输入**：按键映射到 Web 已有的界面命令（与键盘快捷键、命令面板同一组），不新增任何权限，不绕过任何确认。
- **危险操作不能单键完成**：高权限审批（`exec.privileged`）、彻底删除、批准含 full 权限或钩子的计划，需要长按确认（约 1 秒，带进度提示），
  且卡片上照常展示完整内容（完整 argv、job、runtime、理由）。普通提议的批准、任务完成等可以单键，但都有撤销或二次查看的途径。
- **键位存在浏览器里**（与主题、语言相同），不进 Hub；默认键位可直接使用，设置页可改。

## 默认键位（标准布局，Xbox 标注；PlayStation 对应 ✕○□△）

| 键 | 作用 |
|---|---|
| 十字键 / 左摇杆 | 在当前列表或卡片之间移动焦点（按住连续移动） |
| A | 打开详情；在「需要你处理」卡片上为主要动作（批准、接受） |
| B | 返回 / 关闭对话框 / 取消录音 |
| X | 委托（等同 Today 的「委托」按钮，E1-4） |
| Y | 更多操作菜单 |
| LB / RB | 切换模块（Today、任务、知识……） |
| 右摇杆 | 滚动详情、diff 与长文本 |
| RT（按住） | 按住说话（G1-4） |
| Menu / Start | 打开命令面板 |

## 验收要点

- 手柄断开再连上后继续工作；两个手柄同时连接时只响应最后按过键的那个。
- 输入框获得焦点时，手柄除 B（退出输入）与 RT（录音）外不触发界面命令，避免误操作。
- 页面不可见时停止轮询（不在后台持续占用 CPU）。
- 高权限审批、彻底删除用单按 A 不会执行，只有长按完成才执行；长按中途松开即取消。
- 改过的键位刷新后保留；「恢复默认」可用。
- 只用手柄完成一遍：Today 移动 → 委托一个任务 → 打开「需要你处理」→ 批准一个提议 → 按住 RT 说一句话发给 Assistant（G1-4 完成后）。
