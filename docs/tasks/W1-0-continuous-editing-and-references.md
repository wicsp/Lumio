# W1-0：持续编辑、笔记引用与 Markdown 表格公式

- 状态：已实现，本地验收中。
- 必读：`docs/DESIGN.md`、`docs/design/web.md`、`docs/design/knowledge.md`、`docs/design/work.md`。
- 用户要求：内容自动保存、退出不弹丢弃警告，普通引用悬浮与点击，任务/项目说明和讨论引用笔记，以及统一表格/公式渲染。
- 范围：仅 Web 展示与编辑预览，无 API、存储或实体契约变更。

## 决定

1. 所有现有 Markdown 展示入口沿用同一个安全渲染器，增加管道表格、列对齐、单元格内既有行内标记和公式。保留 wiki 链接及笔记导航，原始 HTML 仍转义，外部图片仍不加载。
2. 行内支持 `$…$` 和 `\(…\)`；独立成行支持 `$$…$$` 和 `\[…\]`，后两者允许内容跨行。代码和转义标记保持原样；不完整或无效公式保留源码，流式输出补全后再渲染。
3. Web 引入 KaTeX 0.19.1，输出浏览器原生 MathML；依赖随应用打包，不使用 CDN、远程字体或外部渲染服务，不修改 CSP。关闭 trust，限制公式长度、嵌套深度、宏展开次数和尺寸，每次解析使用独立宏环境，并使用有界缓存。
4. 知识库共用同一表格/公式解析。光标或选择范围进入对应内容时显示原始 Markdown/LaTeX，离开后显示预览；点击或 Enter 可返回源码编辑。保持 Markdown 为唯一正文格式，不做 HTML 反向转换。
5. 助手流式文本以短间隔合并重绘，同样支持表格与公式。任务/项目说明、讨论、执行报告、提问和检查点说明使用同一渲染器。
6. 宽表格与块公式在自身区域横向滚动，避免撑宽手机页面；MathML 继承主题颜色。面向支持原生 MathML 的现代浏览器。

## 依赖选择

KaTeX 提供成熟的 LaTeX 解析，内置类型，无需额外类型包。原生 MathML 避免引入整套字体和放宽内联样式策略。自写公式解析难以正确覆盖分式、上下标与矩阵；MathJax 的运行时及资源方案更重；远程渲染不符合本地数据边界。表格继续在既有渲染器中实现，没有引入另一套 Markdown 依赖。

选项和边界依据：[KaTeX options](https://katex.org/docs/options)、[KaTeX security](https://katex.org/docs/security)。不把全部 LaTeX 或全部 CommonMark/GFM 当作已支持；不能解析的表达式保留可读源码。

## 验证要求

- 表格对齐、转义管道、代码、链接别名、公式单元格、缺失单元格、HTML 与不安全协议。
- 两类行内与两类块级分隔符、流式不完整表达式、代码、货币、转义、无效命令、宏隔离与资源上限。
- 合成数据跨页面验证，知识库预览/源码切换与保存、浅色/深色、窄屏、不放宽 CSP。

## 持续编辑与引用

任务/项目标题直接编辑；说明按用户后续反馈恢复紧凑 Markdown 阅读样式，空内容显示输入占位，单击进入与阅读态同宽高的文本框，仅增加细边框，输入时随内容增高，到达 45vh 上限后框内滚动（原说明已超过上限时保留原高度），失焦后恢复展示。输入停顿 800 ms 自动保存，没有保存/取消按钮，正常保存状态隐藏，失败提示位于说明末尾。知识库仍使用实时 Markdown 编辑器。正文与结构字段遵循现有契约分别串行提交，保存期间的输入继续排队。知识库和 Work 内容保留恢复副本；不完整新建表单、未发送讨论与 AI 输入保留为本地草稿，退出不自动发布。恢复副本的边界见 ADR 0037。

任务/项目说明、讨论与 AI 输入支持 `[[` / `【【` 的上下文候选及标题/正文搜索、命中高亮、上下键选择。Work/对话引用使用稳定 note ID 与标题别名，无 ID 时用根相对 Markdown 链接。普通链接与上标均可悬浮和点击，编辑器卡片保留修改引用源码的入口。阅读态讨论/AI 消息/执行报告的笔记链接可跳转并显示目标摘要。

- 切回已保留的模块时补一次静默刷新，避免显示离开期间已过期的数据。
- 自动保存在 Hub 规范化了提交内容时采用返回值，避免重复提交；任务/项目冲突提示不再写作「笔记」。
