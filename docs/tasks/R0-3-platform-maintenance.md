- 状态：实施中。没有契约变更、没有新依赖，不运行实际安装、升级或检查用户服务。

下载、升级与回退、诊断、配对反馈、Hub 检查已有可测试实现，迁移到 Platform，避免跨应用复制。
平台库接收显示回调与调用方版本，不自行打印或决定 CLI 退出码；应用保留参数解析和默认终端显示。
原 app 入口可薄转发，类和函数保持相同行为；业务包不依赖 Platform。

## 顺序与验证

1. Platform：移动共用规则与系统适配，直接测试合成 HTTP 下载、校验、升级失败回退，不引用任何 app。
2. CLI：改为共享实现，保留版本、错误类型、参数、显示和退出码，旧测试继续覆盖。
3. Runtime：同样接入；后台与命令模式不会读错另一个应用的版本。
4. Hub：改用共用 Hub 检查；安装与配对验证沿用假服务和临时目录。

每步单独运行 bun run check 后提交推送；不修改版本或实际安装服务。最终依赖检查确保 packages 不依赖 apps、apps 不互相引用。
