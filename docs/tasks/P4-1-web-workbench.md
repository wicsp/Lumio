# P4-1 Lumio Web 工作台

- 用户授权：2026-11-01「顺便再给我写一个 GUI」。先按可跨设备浏览的 Web GUI 实现。
- 范围：仅 apps/web（含测试）与对应文档、新 workspace 锁项与浏览器独立类型检查配置；不改 schema、Hub 或其他业务模块。
- 前端基础由 Claude 编写；Codex 接手接口集成、补齐完整四模块操作、测试、浏览器验收与修正；同一时刻仅一个写入者。
- 依据：现有 DESIGN 四模块边界、既有 Hub/SDK/契约；新增 GUI 决策 ADR 0026 与 DESIGN 同步。
- 无新第三方依赖：使用原生 TypeScript/DOM/CSS 与 Bun 构建，只依赖既有 api-client/schema。

## 交付与验收

1. 固定 Hub 的同源代理、一次性配对码或 human 令牌连接；凭据只在内存，退出/401 中止请求并清空数据。
2. 响应式中文工作台与可访问导航、真实总览、空/加载/错误/断线状态；一个模块失败不拖垮其他模块。
3. 知识搜索、类型过滤、安全 Markdown 阅读和链接；私密内容显式 opt-in，关闭后旧请求不得重新显示私密结果。
4. Project/Task 创建、过滤、结构化字段及独立描述编辑、讨论、执行关联与显式派活；带版本保存，冲突不覆盖草稿。
5. Job 过滤/详情/结果/取消/产物下载，设备能力与在线状态；数据库 Routine 创建、修改、暂停/恢复。
6. Assistant 历史对话/新轮次/流式显示/停止与中断后核查、显式记忆管理；不增加工具、委托或私密权限。
7. 审批列表与完整命令、参数、来源和理由展示；人明确接受/拒绝，不自动执行。
8. 模块只通过 SDK 与 Hub 协作，浏览器无业务库/文件访问或 server-only 依赖；代理路径/方法/来源/大小/时限/头部受控。
9. 新功能有 Bun 与契约测试；真实浏览器在合成 Hub/知识库/模型环境验证主要流程、隐私、冲突与 390px 布局。
10. 提交前完整 bun run check、应用构建、只读交叉 review、git diff --check；提交推送后保持工作区干净。

不读取真实 vault，不连接或修改用户实际 Hub/服务，不调用真实模型或 agent，不安装或发布。知识目前只读，正文仍可用外部编辑器；不添加缺乏既有契约的知识编辑按钮。

浏览器与 Bun 服务端独立编译检查；DOM 全局类型不能污染其他 app 的 Bun 类型。根 typecheck 脚本串联两套检查，其他业务代码不改。

## 试用反馈：窄屏导航下方空白（2026-11-01）

- 复现：审批为空列表时，650×900 窗口中导航底部为 138px、主工具栏顶部为 353.8px，出现约 216px 空白。shell 的 min-height 与默认 Grid auto 行拉伸共同导致空余高度进入导航行。
- 修正：仅在 860px 及以下为 shell 设置 align-content:start，保留导航与主内容的自然高度；不改变桌面侧栏规则。
- 浏览器实测 390、650、860、861、1280px：窄屏导航与工具栏间距为 9–10px，无横向溢出；桌面侧栏仍为 900px、工具栏位于顶部。650px 修正前后截图已人工核对。
- 完整 LUMIO_LIVE=0 bun run check：857 pass、3 skip、0 fail，860 tests / 98 files；git diff --check 通过。此次为样式修正，未修改契约或新增依赖。
