# Personal：个人日程、待办与生活日志

> [ADR 0080](../adr/0080-personal-scheduling-and-journal.md) 定义模块、同步和授权边界。本文描述 Schema 契约。

- 日程、个人待办与生活日志分别使用 `pev_`、`ptd_`、`jrn_`。引用从 `ResourceRef` 的 `personal` 模块表达，引用中不保存私密标题。关联 Work Task 仅建立引用。
- 全天日程用当地日期和排他的结束日。定时日程带偏移和 IANA 时区，按实际时刻校验顺序。待办截止时间独立于日程，可为日期、带时区的时刻或未指定。定时日程列表可返回无标题的忙碌区间。未验证可安全编辑的条目标为只读。
- 日志区分人工或聊天记录、CalDAV 完成观测、撤销完成、更正和撤回。能取得远端完成时间时独立于观测时间保存。聊天录入只接收描述、实际日期或时刻及可选引用，来源由 Hub 填写。
- 创建和修改命令使用 `request_id` 去重，修改带 `expected_revision`。未提供的更新字段不变，可清空字段通过 `null` 清除。审批待定、同步待定、已确认、冲突与待核实各有独立结果。
- Personal 能力契约单独导出，由已获授权的所有者前台对话注册。日志查询须由所有者为当前轮选择范围。私密提议绑定所有者和会话，保留待批准的原命令。只有所有者可批准。个人待办完成和撤销使用 human 命令。

## 同步与存储

- `packages/personal` 通过存储端口核对游标、计算对象版本和记录待办状态变化。`packages/storage` 以单个 SQLite 事务更新同一集合的游标、投影和生活日志。已移除的对象保留 ID 映射，全量报告收齐后才按缺失对象处理。
- 已授权的命令先保存请求回执及写入条件。创建时保留稳定 UID，修改时保留上次读取的 ETag。Hub 的 CalDAV 传输层仅对配置的 HTTPS 集合发送凭据，拒绝重定向和越界资源，收齐分页并验证 ETag 后才交给对账。
- Hub 复用仓库已有的 XML 校验库验证 DAV 报告完整性。容错 DOM 解析可能接受截断响应，完整性校验是全量对账确认删除的前提。

## 私密聊天与 Web

- 「个人」页提供专用聊天、个人提议、未来七天日程、待办和最近七天日志。Today 将当日日程和到期待办显示在个人区块。普通聊天的页面选区、工作待办、通用审批、通知和后台预读不接收这些内容。
- 日程和待办由前台聊天提出，个人页显示对象、日期、变更和审批结果。提议在 24 小时内有效。批准把命令保存到队列，条件写入后核对 UID、请求标记与目标字段，再返回确认。远端已变更时显示冲突，由所有者重新提出并批准。
- 所有者可在个人页标记或撤销完成，也可记录、更正或撤回生活日志。日志更改追加来源和目标引用；CalDAV 的完成和撤销记录来自实际读到的状态变化。
- 个人聊天使用 Hub 上的 Lumio API 配置；默认取首个可用的 Lumio 聊天配置。每条消息可以单独授权一个日志日期范围。授权日志的回复不带入下一轮模型输入。个人聊天回执、使用者的提议与日志均绑定所有者，不写入普通助手会话。
- 首版只写单次日程及普通待办。复杂日程可能包含未展开的重复实例；确认排期前检查 Apple 日历上的完整视图。

## 启用 CalDAV

在 Hub 服务环境配置 `LUMIO_PERSONAL_OWNER`（所有者的 `act_…` ID）、`LUMIO_PERSONAL_EVENTS_URL`、`LUMIO_PERSONAL_TODOS_URL`、`LUMIO_PERSONAL_USERNAME`、`LUMIO_PERSONAL_PASSWORD` 与 `LUMIO_PERSONAL_TIMEZONE`。时区缺省为 `UTC`。省略账户配置时关闭个人入口的数据和 Agent 工具。通过服务的私密配置渠道设置口令。

两个集合分别只接受 `VEVENT` 和 `VTODO`，同属受信任 HTTPS 下的 Lumio 专用账户。Apple 客户端添加同一个账户的发现地址。上线前用合成日程和待办做端到端验证，再启用真实账户。备份 Hub 数据与 CalDAV 专用账户数据，恢复后从两端当前版本对账。
