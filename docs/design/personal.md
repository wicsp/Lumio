# Personal：个人日程、待办与生活日志

> [ADR 0080](../adr/0080-personal-scheduling-and-journal.md) 定义模块、同步和授权边界。本文描述 Schema 契约。

- 日程、个人待办与生活日志分别使用 `pev_`、`ptd_`、`jrn_`。引用从 `ResourceRef` 的 `personal` 模块表达，引用中不保存私密标题。关联 Work Task 仅建立引用。
- 全天日程用当地日期和排他的结束日。定时日程带偏移和 IANA 时区，按实际时刻校验顺序。待办截止时间独立于日程，可为日期、带时区的时刻或未指定。定时日程列表可返回无标题的忙碌区间。未验证可安全编辑的条目标为只读。
- 日志区分人工或聊天记录、CalDAV 完成观测、撤销完成、更正和撤回。能取得远端完成时间时独立于观测时间保存。聊天录入只接收描述、实际日期或时刻及可选引用，来源由 Hub 填写。
- 创建和修改命令使用 `request_id` 去重，修改带 `expected_revision`。未提供的更新字段不变，可清空字段通过 `null` 清除。审批待定、同步待定、已确认、冲突与待核实各有独立结果。
- Personal 能力契约单独导出，由已获授权的所有者前台对话注册。日志查询须由所有者为当前轮选择范围。私密提议绑定所有者和会话，保留待批准的原命令。只有所有者可批准。个人待办完成和撤销使用 human 命令。
