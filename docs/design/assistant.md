# Assistant：内置助手

> 现行设计分册，只写现在生效的规则；总览、跨模块规则与写法见 [`../DESIGN.md`](../DESIGN.md)。

## 对话、模型与记忆（ADR 0025、0027、0029）

- `/v2/assistant/chat` 支持 JSON 与 NDJSON；对话、轮次、工具调用和记忆归 Assistant。CLI 用 `chat`、`chat list/show`。
  模型和工具通过注入接口提供。Hub 的兼容 Chat Completions 适配器须配置 LUMIO_ASSISTANT_BASE_URL 与 LUMIO_ASSISTANT_MODEL，凭据仅运行时环境注入；无默认供应商或模型。用 `lumio hub assistant setup` 配置：验证后写入 Hub 服务的私有环境文件（600，与 Hub 令牌同一文件）并重启，密钥只从隐藏输入或标准输入读取，不经命令行参数、不进日志（ADR 0027）。支持 SSE 与 JSON 响应，限制响应字节/时限，工具仅在完整响应校验后交付，不自动重试。
  模型设置和显式记忆见 [助手使用说明](../assistant.md)。按 ADR 0029（R3 实施中）：助手接上能力目录，可读取与做低风险写入；模型也可在 Web 设置页配置，写入后进程内重载，不再重启。
- `chat memory list/remember/forget` 经严格 v2 记忆命令显式管理偏好；仅 human 可操作自己拥有的记忆，行、幂等回执和成功审计同事务提交。遗忘会清除活动记忆和回执中的内容，重放旧请求返回 tombstone；既有对话、模型请求快照和历史备份独立保留。
- **任务委派与交接计划**（ADR 0056）。兼容 API 和原生助手通过能力目录提交委派与设置计划的提议，由人批准。批准设置计划后只保存计划。原生会话在创建时确定工具集合，新增工具在新会话可用。
- 工具执行使用持久的独立 agent 身份，human 仅作为对话所有者；默认没有生产工具或来源读取适配器。带来源记忆在保存、重放与使用时以 agent 权限重查，无法访问或私密内容不交付模型。
- 每次模型调用前以既有 AssistantModelRequest 保存不可变请求快照、序号、时间与工具 agent；写入失败不调用模型。快照是准备调用的记录，不代表远端已收到，不用于自动重放，也不提供绕过来源权限的读取接口。每次模型请求前重新筛选记忆。
- 助手持久化工具调用状态；中断或写操作结果不明标为 unknown，不自动重放。最终空回复明确失败，工具调用中间消息可无文本。个人工具范围见 [Personal](personal.md)。
- **删除对话**（ADR 0038，D1）：只有人能删除自己的对话，正在生成时先停止；移入回收站，30 天内可恢复。从对话保存的记忆是独立记录，不随对话删除。

## 统一 AI 配置与原生 Assistant（ADR 0041、0042、0047）

> 删除配置的契约扩展见 [ADR 0043](../adr/0043-ai-configuration-deletion.md)（Accepted，S1-3）。human 可删除自己拥有的 Connection 和 Profile。仍被 Profile 引用的 Connection 或仍被未关闭的原生会话引用的 Profile 会拒绝删除。

- Connection 负责来源/设备与私有凭据，Profile 负责引擎/模型/原生思考档位，用途绑定负责权限；共用 Profile 不共用工具与沙箱。API 连接当前在 Hub，Codex 连接在指定 Runtime。旧 API 设置保留兼容。
- TypeSafe Jev Connection 使用固定的官方 System One API 地址，由 Hub 保存私有 API 密钥。现阶段支持连接管理，保存和读取不调用推理，且不能用于聊天 Profile（ADR 0046）。
- 旧 API 配置在 Hub 启动、接收请求之前迁入已有 human 所有者的兼容 Connection/Profile；每个所有者的两项配置与一次性回执在同一事务提交，已有配置优先。GET 只读，不生成配置；后续移除配置也不重新导入。原私有环境文件保留（PR #120 review 修复）。
- 原生 conversation 独占持久 CODEX_HOME、workspace 与 app-server，同 thread 续接和压缩；新对话使用所属 Connection 在执行器上的一次官方登录；Lumio 只调用原生端口，不套第二层工具循环或摘要汇报模板。公开事件与每轮交付快照独立保存，不声称记录官方内部全部模型请求。
- 恢复必须首次携带完整配置并校验账户/版本/工具/沙箱；状态丢失显式失败。模型与 effort 可逐轮切换，安全/账户/上下文变化新建环境。记忆或来源可见性变化使旧上下文停用，不宣称引擎已经忘记。
- 浏览器离开不取消原生运行。普通停止在收到该轮官方中断终态、且无未确认副作用后可续聊；活跃断线、未确认停止和未知副作用保守冻结，禁止自动重放。人工核查工具结果并确认相关进程已停止后关闭旧环境再新建。界面保留正文、公开思考摘要、工具与审批记录。
- DeepSeek Profile 可启用已验证思考参数，隐藏续接状态持久保存并用于后续工具请求，不混进正文。未知兼容端点只提供默认思考设置。
- **连接用量（ADR 0052、0054）**：用量与 Profile、对话独立，仅连接所有者可读取或设置监控。Hub 查询固定官方 DeepSeek 余额地址，Codex 额度由连接所在 Runtime 的 App Server 返回。Claude Code 订阅连接支持会话状态栏采样，也可显式开启后台查询。启用监控后，Hub 每 15 分钟在连接绑定的在线 Runtime 调度一次后台查询，页面也可手动刷新。后台查询成功即更新查询时间，临时查询失败或 Runtime 离线保留最近读数与原时间。登录失效或身份无法核实会清除旧读数，确认换账号后须重新绑定。Hub 保留最近成功快照、采集状态与阈值提醒去重记录，换绑或换凭据使旧读数失效。过期或缺失数据保持可辨识。API 余额的「余额低于」提醒阈值与监控阈值都只填一个数字、不分币种，按显示的那笔余额判断；侧栏细条在余额不低于监控阈值时满格、低于时按比例缩短，只影响显示（ADR 0071）。
- **Agent 并发（ADR 0079）**：同一账号或上游配额跨执行器共享名额。默认 Codex 4、Claude Code 2，未经配置的 Pi 1。用户可将无法验证上游等价关系的连接关联到同一配额组。原生 Agent 轮次也占同一份额度，执行结果未确认时保留名额。
- **阿里云账户余额（ADR 0058）**：DashScope 语音连接和使用官方百炼地址的兼容 API 连接可由所有者单独绑定 RAM 只读凭据。Hub 仅手动刷新固定阿里云账务端点，保存账户现金余额、可用额度及原币种。凭据轮换、清除、授权失效和连接端点变更使旧读数失效。
- 聊天流可显式订阅每次模型调用开始与思考片段事件（ADR 0050）。仅官方 DeepSeek 思考模式的可见文本进入该轮的实时事件，内部密文和已保存的续接状态留在 Hub。原生 Codex 继续通过带序号的原生事件提供公开摘要。两种引擎均可为下一轮覆盖模型与思考档位。

## 语音（ADR 0055，Accepted，S1 实施中）

- 浏览器采集 16 kHz 单声道 PCM16，经 Hub 的 `/v2/speech/transcribe`（WebSocket）转给语音服务；浏览器不直连服务商，Runtime 不参与，也不提供模拟系统按键的能力。
- 语音识别与合成是统一 AI 配置的新用途 `speech.asr`、`speech.tts`，沿用 Connection / Profile / 用途绑定；默认云端 API，本地模型以后作为 Runtime 上的可选连接。
- 首个服务商为阿里云百炼 Fun-ASR（连接类型 `dashscope`，只接受官方区域地址，默认北京）；语音 Profile 的引擎为 `speech`，只能与语音连接配对，不能用于聊天（S1-2）。
- 不保存原始音频与中间结果；日志只记元数据。只有 human 可用，语音不进入能力目录。热词只来自人维护的词表与非私密项目名；需要时同步为服务商保存的词表，设置页注明。
- `GET/PUT /v2/speech/vocabulary` 管理热词表及同步状态，`GET/PUT /v2/speech/bindings` 管理语音用途绑定。Fun-ASR 使用北京固定域名，热词权重为 4。连接删除前先清理远端词表，删除语音 Profile 时解除对应绑定（S1-3，ADR 0043）。
- 识别结果只填入输入框，与键盘输入等价，由人确认后发送；语音不能代替任何确认。
- 语音合成采用 ASR → LLM → TTS 串联，只朗读口语摘要，可打断；不采用端到端实时语音模型。

## 全局捕获键（ADR 0066，Accepted，C1 实施中）

- macOS 菜单栏小助手 `apps/desktop` 是 human 客户端。令牌存钥匙串，只在物理按键时采集。
- **轻点**存资料，**按住**说话。松开后把原话和所见发给主对话，Esc 取消。
- **所见**（`gln_`）：窗口截图、光标与轨迹、选区、本机 OCR、App、窗口和网址。已配对扩展可在同一次按键附上网页正文（ADR 0081）。
  Hub 挑"指向的段落"：选中文字优先，其次轨迹围出的区域，再次光标所在段落。网址属于本 Hub 的 Web 时不截图，按焦点处理。
- 主对话的 `glance` 与 `focus` 互斥。所见作为数据进当前轮，私有正文片段仅供当轮读取。收藏工具只作用于本轮所见，不进能力目录；批准在 Lumio 中进行。
- 语音先存原话 Idea，再用前台工具处理请求。只记想法可静默；可同轮建单并提议委派，用户在 Lumio 批准（ADR 0074、0078）。
- 默认发送本机识字；绑定 `knowledge.vision` 后收藏同时发送截图，官方 DeepSeek Flash 主对话同轮接收截图、识字和原话。缺图时沿用文字（C1-2、C1-7）。
- 捕获轮同次回复决定相关摘录、图片和来源（ADR 0076）。Hub 校验逐字摘录后附加到 Idea，不覆盖人的修改。其余 OCR、选区、轨迹、无关页面锚点和截图在本轮结束时清理；失败或取消保留原话，pending 清理可重启恢复。显式收藏资料沿用资料生命周期；旧所见不重分类。
- 捕获请求快照只持久化原话、所见 ID、模型设置与工具目录，不存候选 OCR、焦点和思考续接；图片只记文件 ID 与 SHA-256。截图仍会发给模型，清理不删除既有备份或供应商数据。
- iPhone 快捷指令（`apps/mobile`）发送截图及整图 OCR（`ios-vision@1`），App 记为 `iPhone`，无光标、选区、窗口和网址，渠道为 `share`。两条快捷指令共用 iCloud `快捷指令/Lumio/config.json`；设置页通过「Lumio 收藏」配对并同步界面语言，改语言后重配，旧配置默认中文（ADR 0075）。签名包不含地址或令牌，安装与签名见 `apps/mobile/README.md`。

## 单入口助手（ADR 0059、0060 Accepted，0061 部分 Accepted；试用中）

- 每个 human 一个主对话，不按项目或想法切换窗口。消息的话题锚点（ResourceRef，可多个）存在 Assistant 内部关联表，不进 `AssistantMessage` 契约。每轮按锚点组装上下文：当前锚点对象和同锚点历史片段的摘要直接放入，一跳关联只放 ID 和摘要，其余按 ID 取回；不对对话做语义检索。话题切换在对话里显示分隔提示。首期只用于兼容 API 助手。
- 片段摘要在后台生成，按来源消息范围去重；切回时还没有摘要就放最近几轮完整交互（工具调用与结果成对保留），不等模型。
- 前台可靠性修复（[assistant-reliability](../tasks/assistant-reliability.md)）：澄清与话题锚点不裁减当前工具目录；是否追问由模型结合当前焦点和可用工具判断，操作仍走原有授权。每次模型请求附当前 UTC 时间和工具能力事实，历史中的能力声明不代表当前能力。时区未提供时不把 UTC 当作用户时区。
- 历史预算优先保留紧邻上一轮的问答，再保留近期和同话题历史；大结果可压成有来源与状态的短回执。明确只要求重述上一答时使用无工具的改写路径；上一答不可见时不拿更早的答复替代。任务、提议与执行轮次的回执按实际结果区分。失败、取消、结果未知的轮次保留其状态；当前轮次的工具对和供应商续接不裁剪。含私密读取的旧轮次不回放，其他历史逐次重查来源可见性（assistant-reliability）。
- 话题恢复与主动展示（assistant-reliability 第四、五阶段）：从旧锚点、成功读取／导航的对象及对话引用生成有界候选目录，以原话匹配排序，逐次重查来源；不新建会话或长期记忆。模型用现有导航工具选择讨论对象，成功发出请求后更新后续消息锚点，并在同轮补入相关历史。确定具体对象后主动打开，相关材料用展示面板列出；浏览器仍可按人的操作暂缓跳转。当前及上轮焦点都有采集时间，页面变化不等于先前回答有误，导航请求也不等于浏览器已显示。
- 可按要求存讨论为 Idea。建单附语音 Idea 或保存近期问答和原消息链接；跳过私密读取历史。任务描述链接到 Idea（ADR 0078）。
- 平时保留聊天历史；有结论可建议沉淀。轻活自己做，重活走委派。
- 执行结束、待批准提议、Inbox 捕获、Watchdog 报告触发后台预读。执行结果由 Work 记录一次，预读生成提醒；任务详情隐藏与原结果关联的历史预读副本（A1-7）。预读不进入正在进行的一轮；改任务字段时带 `expected_revision`，冲突重读后重新判断。按重要、待处理、静默分级；重要的在当前一轮结束后插话，待处理的进入 Today 并标未读。首期不接外部事件。
- Watchdog 是 Hub 内的定时只读巡检（`LUMIO_WATCHDOG_INTERVAL_MINUTES`，默认 30 分钟，0 关闭），报告执行器 30 分钟没回报或运行超过 6 小时的轮次、交给 agent 或外部却 14 天没有变化的任务，同一天相同的发现只报一次；不停止、不修改任何东西。执行器失联暂不报告：执行器 ID 不是 ResourceRef 能指向的对象，需要先改契约（A1-8）。
- 提前探索（`/v2/explorations`，只授予 human）只在人标记过的想法、任务、项目上运行，以助手的 agent 身份只用只读能力，不走对话里的私密读取例外；token 与时间预算默认 20 万与 30 分钟（`LUMIO_EXPLORATION_MAX_TOKENS`、`LUMIO_EXPLORATION_MAX_MINUTES`），用完即停。有发现时写一份 AI 笔记（`derived_from` 指向目标）并按闸门分级提醒，没有发现或用完预算时静默记录；Hub 重启时还在运行的探索记为失败，不自动重跑（A1-9）。
- 浏览器随消息发送焦点快照，助手用展示工具操作工作台，规则见 [web.md](web.md)。
- 事件分级与进展判断由 Hub 的判断闸门完成，主助手不参与；对话授权尚未启用，见 [security.md](security.md)。
