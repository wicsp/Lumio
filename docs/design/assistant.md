# Assistant：内置助手

> 现行设计分册，只写现在生效的规则；总览、跨模块规则与写法见 [`../DESIGN.md`](../DESIGN.md)。

## 对话、模型与记忆（ADR 0025、0027、0029）

- `/v2/assistant/chat` 支持 JSON 与 NDJSON；对话、轮次、工具调用和记忆归 Assistant。CLI 用 `chat`、`chat list/show`。
  模型和工具通过注入接口提供。Hub 的兼容 Chat Completions 适配器须配置 LUMIO_ASSISTANT_BASE_URL 与 LUMIO_ASSISTANT_MODEL，凭据仅运行时环境注入；无默认供应商或模型。用 `lumio hub assistant setup` 配置：验证后写入 Hub 服务的私有环境文件（600，与 Hub 令牌同一文件）并重启，密钥只从隐藏输入或标准输入读取，不经命令行参数、不进日志（ADR 0027）。支持 SSE 与 JSON 响应，限制响应字节/时限，工具仅在完整响应校验后交付，不自动重试。
  模型设置和显式记忆见 [助手使用说明](../assistant.md)。按 ADR 0029（R3 实施中）：助手接上能力目录，可读取与做低风险写入；模型也可在 Web 设置页配置，写入后进程内重载，不再重启。
- `chat memory list/remember/forget` 经严格 v2 记忆命令显式管理偏好；仅 human 可操作自己拥有的记忆，行、幂等回执和成功审计同事务提交。遗忘会清除活动记忆和回执中的内容，重放旧请求返回 tombstone；既有对话、模型请求快照和历史备份独立保留。
- **任务委派与交接计划**（ADR 0056）。兼容 API 和原生助手通过能力目录提交委派与设置计划的提议，由人批准。批准设置计划后只保存计划。原生会话在创建时确定工具集合，新增工具在新会话可用。
- 工具执行使用持久的独立 agent 身份，human 仅作为对话所有者；默认没有生产工具或来源读取适配器。带来源记忆在保存、重放与使用时以 agent 权限重查，无法访问或私密内容不交付模型。
- 每次模型调用前以既有 AssistantModelRequest 保存不可变请求快照、序号、时间与工具 agent；写入失败不调用模型。快照是准备调用的记录，不代表远端已收到，不用于自动重放，也不提供绕过来源权限的读取接口。每次模型请求前重新筛选记忆。
- 助手持久化工具调用状态；中断或写操作结果不明标为 unknown，不自动重放。最终空回复明确失败，工具调用中间消息可无文本。
- **删除对话**（ADR 0038，D1）：只有人能删除自己的对话，正在生成时先停止；移入回收站，30 天内可恢复。从对话保存的记忆是独立记录，不随对话删除。

## 统一 AI 配置与原生 Assistant（ADR 0041、0042、0047）

> 删除配置的契约扩展见 [ADR 0043](../adr/0043-ai-configuration-deletion.md)（Accepted，S1-3）。human 可删除自己拥有的 Connection 和 Profile。仍被 Profile 引用的 Connection 或仍被未关闭的原生会话引用的 Profile 会拒绝删除。

- Connection 负责来源/设备与私有凭据，Profile 负责引擎/模型/原生思考档位，用途绑定负责权限；共用 Profile 不共用工具与沙箱。API 连接当前在 Hub，Codex 连接在指定 Runtime。旧 API 设置保留兼容。
- TypeSafe Jev Connection 使用固定的官方 System One API 地址，由 Hub 保存私有 API 密钥。现阶段支持连接管理，保存和读取不调用推理，且不能用于聊天 Profile（ADR 0046）。
- 旧 API 配置在 Hub 启动、接收请求之前迁入已有 human 所有者的兼容 Connection/Profile；每个所有者的两项配置与一次性回执在同一事务提交，已有配置优先。GET 只读，不生成配置；后续移除配置也不重新导入。原私有环境文件保留（PR #120 review 修复）。
- 原生 conversation 独占持久 CODEX_HOME、workspace 与 app-server，同 thread 续接和压缩；新对话使用所属 Connection 在执行器上的一次官方登录；Lumio 只调用原生端口，不套第二层工具循环或摘要汇报模板。公开事件与每轮交付快照独立保存，不声称记录官方内部全部模型请求。
- 恢复必须首次携带完整配置并校验账户/版本/工具/沙箱；状态丢失显式失败。模型与 effort 可逐轮切换，安全/账户/上下文变化新建环境。记忆或来源可见性变化使旧上下文停用，不宣称引擎已经忘记。
- 浏览器离开不取消原生运行。普通停止在收到该轮官方中断终态、且无未确认副作用后可续聊；活跃断线、未确认停止和未知副作用保守冻结，禁止自动重放。人工核查工具结果并确认相关进程已停止后关闭旧环境再新建。界面保留正文、公开思考摘要、工具与审批记录。
- DeepSeek Profile 可启用已验证思考参数，隐藏续接状态持久保存并用于后续工具请求，不混进正文。未知兼容端点只提供默认思考设置。
- **连接用量（ADR 0052、0054）**：用量与 Profile、对话独立，仅连接所有者可读取或设置监控。Hub 查询固定官方 DeepSeek 余额地址，Codex 额度由连接所在 Runtime 的 App Server 返回。Claude Code 订阅连接支持会话状态栏采样，也可显式开启后台查询。启用监控后，Hub 每 15 分钟在连接绑定的在线 Runtime 调度一次后台查询，页面也可手动刷新。后台查询成功即更新查询时间，临时查询失败或 Runtime 离线保留最近读数与原时间。登录失效或身份无法核实会清除旧读数，确认换账号后须重新绑定。Hub 保留最近成功快照、采集状态与阈值提醒去重记录，换绑或换凭据使旧读数失效。过期或缺失数据保持可辨识。
- **阿里云账户余额（ADR 0058）**：DashScope 语音连接和使用官方百炼地址的兼容 API 连接可由所有者单独绑定 RAM 只读凭据。Hub 仅手动刷新固定阿里云账务端点，保存账户现金余额、可用额度及原币种。凭据轮换、清除、授权失效和连接端点变更使旧读数失效。
- 聊天流可显式订阅每次模型调用开始与思考片段事件（ADR 0050）。仅官方 DeepSeek 思考模式的可见文本进入该轮的实时事件，内部密文和已保存的续接状态留在 Hub。原生 Codex 继续通过带序号的原生事件提供公开摘要。两种引擎均可为下一轮覆盖模型与思考档位。

## 语音（ADR 0055，Accepted，S1 实施中）

- 浏览器采集 16 kHz 单声道 PCM16，经 Hub 的 `/v2/speech/transcribe`（WebSocket）转给语音服务；浏览器不直连服务商，Runtime 不参与，也不提供模拟系统按键的能力。
- 语音识别与合成是统一 AI 配置的新用途 `speech.asr`、`speech.tts`，沿用 Connection / Profile / 用途绑定；默认云端 API，本地模型以后作为 Runtime 上的可选连接。
- 首个服务商为阿里云百炼 Fun-ASR（连接类型 `dashscope`，只接受官方区域地址，默认北京）；语音 Profile 的引擎为 `speech`，只能与语音连接配对，不能用于聊天（S1-2）。
- 不保存原始音频与中间结果；日志只记元数据。只有 human 可用，语音不进入能力目录。热词只来自人维护的词表与非私密项目名；需要时同步为服务商保存的词表，设置页注明。
- `GET/PUT /v2/speech/vocabulary` 管理热词表及同步状态，`GET/PUT /v2/speech/bindings` 管理语音用途绑定。Fun-ASR 使用北京固定域名，热词权重为 4。连接删除前先清理远端词表，删除语音 Profile 时解除对应绑定（S1-3，ADR 0043）。
- 识别结果只填入输入框，与键盘输入等价，由人确认后发送；语音不能代替任何确认。
- 语音合成采用 ASR → LLM → TTS 串联，只朗读口语摘要，可打断；不采用端到端实时语音模型。
