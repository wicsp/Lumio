# Web 工作台

> 现行设计分册，只写现在生效的规则；总览、跨模块规则与写法见 [`../DESIGN.md`](../DESIGN.md)。
> 功能、页面与快捷键见 [`apps/web/README.md`](../../apps/web/README.md)（ADR 0036：设计文档不写界面交互细节）。

网页由 Hub 提供；决定见 ADR 0026、0027。

- **技术栈**：原生 TypeScript、DOM 与 CSS，用仓库固定的 Bun 1.4.4 构建静态资源，由 Hub 提供（2026-11-08 人类批准 Bun 1.4 升级）。业务依赖 `@lumio/api-client` 与 `@lumio/schema`；笔记编辑集成 CodeMirror 6 的 state/view/commands/language/lang-markdown/autocomplete（ADR 0035）。
  Hub 为每次 HTML 响应生成样式 nonce，允许编辑器动态样式，不放宽脚本 CSP。公式使用随包提供的 KaTeX，输出原生 MathML，不加载远程渲染资源（W1-0）。
- **类型隔离**：浏览器端与服务端是两个独立的 TypeScript 程序，根 typecheck 同时检查两者。
- **访问路径**（ADR 0027）：网页由 Hub 在自己的地址上提供（单机 `http://127.0.0.1:7420`；服务器模式为 Hub 的对外地址），浏览器与 Hub 同源，直接调用 `/v1`、`/v2`。
  Hub 为页面与资源设置限制性 CSP；浏览器请求（带 `Origin` 或 `Sec-Fetch-Site`）的 Host 和所带 Origin 必须对应本机监听地址、`LUMIO_PUBLIC_URL` 或 `LUMIO_WEB_ORIGINS`。插件的 `chrome-extension://` 和 `moz-extension://` Origin 也允许，仍校验 Host 并按令牌鉴权（I1-7a）。
- **会话**：先用 `lumio login-code --name web` 配对。身份验证后，默认以 sessionStorage 保留当前标签页登录，刷新自动恢复；勾选「记住这台设备」时使用 localStorage，关闭重开仍可恢复。仅保存凭据，按网页所在的 Hub 来源隔离。恢复前验证 human 身份。同源脚本可读，受现有 CSP 与安全渲染保护；不等同 HttpOnly 或钥匙串隔离。验证遇到 401/403 或登出时清除对应凭据，任何 401 或登出中止请求、清空模块；临时断线保留凭据并允许重试。存储受限时降级并提示，除恢复副本外不缓存业务数据，不直接访问 vault。
- **数据规则**：私有内容须显式开启；知识的新建与编辑规则见 [knowledge.md](knowledge.md)；任务与项目的结构化字段与描述分开提交并带 revision，内容编辑可自动保存；评论与委派是独立的显式操作；
  执行结果中的文件下载要校验大小与 SHA；助手会话可查看已保存状态，不重放；高权限审批必须展示完整 argv、job、runtime 与理由，由人显式接受或拒绝。
- **恢复副本**（ADR 0037）：会话存储之外，正在编辑的内容、未发送输入和未完成表单允许保留当前浏览器恢复副本，按 Hub 与已验证凭据的哈希隔离。它不是业务数据镜像或权威存储；不保存密码/密钥控件，不自动发布消息或执行动作。写入仍检查版本并沿用幂等请求；存储不可用时明确提示限制。
- **渲染**（W1-0）：所有正文共用安全 Markdown 子集，包含表格与行内/块级公式；无效公式保留源码。转义原始 HTML，过滤不安全协议，不加载外部图片；公式关闭 trust 并限制解析资源。沿用 source/private 过滤，并丢弃过期请求的结果。
- **工作内容中的知识引用**（W1-0）：说明、讨论和对话复用知识库候选搜索；插入稳定 note ID（无 ID 时使用根相对路径），不依赖工作对象不存在的 vault 目录。引用不是自动读取私密笔记或授权模型访问来源的通道。
- **主题与语言**（ADR 0028）：主题与界面语言可切换，默认分别跟随系统与浏览器语言，选择只保存在本浏览器；请求带 `Accept-Language`。
- **桌面侧栏**：浏览器记住收起状态，收起时保留导航图标的位置。窄屏沿用底部导航。
- **任务结构**（ADR 0039，T1-4）：轮到你的待办若有未完成前置，单独归入「等待前置」组（需要你处理的提问、验收、失败不受影响），行上标出还差几个；被阻塞时委派按钮禁用并说明缺哪些前置。
  任务详情可编辑前置、父任务与标签（项目可编辑标签）：候选在界面上排除自己和会成环的任务，最终以 Hub 校验为准；已取消、已删除的前置照常列出并标注。详情列出「等这个任务的任务」与子任务（进度不计已取消），可预填父任务新建子任务；任务列表可按标签筛选。
  项目详情的任务区可切换「依赖图」（T1-5）：未完成任务按依赖自左向右分层，可开工的高亮，项目外未完成的前置以虚线标出；超过 50 个未完成任务时只提示改用列表。
- **一键委托**（ADR 0044，E1-4）：Today 待办组里轮到你（todo）且有 `next_target` 的任务，行右侧有「委托」按钮，一次点击派出；小箭头可换目标（之后沿用新目标）；被阻塞时禁用；没有 `next_target` 的不显示。项目详情可编辑默认执行者。
- **交接图编辑**（ADR 0049，H1-7）：计划编辑器是逐行列表，同一行的步骤并行，不做连线画布；无法按行表示的计划保留各步骤的 after，只能编辑内容。agent 步骤可设访问范围、Git、密钥与前后钩子（命令按 argv 保存，不经过 shell），执行者没有沙箱时提示权限无法强制；可选「计划走完自动完成」（需要检查点）。
  计划与模板提议在批准卡片上完整列出每一步的权限与钩子命令，含 full 权限、钩子或密钥时提示逐步检查。项目详情可设默认计划（来自计划模板）。并行执行时任务显示每个分支的 agent。
  权限申请（H1-9）：一轮以权限申请结束时，「需要你处理」卡片显示 agent 的理由与申请的各项，只能勾选申请里有的项，选择只给下一轮或这个任务（有计划时为这一步）以后都给；批准即续接会话，拒绝须写明原因并按回答继续。
  管理员权限助手（ADR 0020）：设置页「Hub 与执行器」显示每台执行器是否已装，未装时说明用途并给出可复制的安装命令；一轮里 agent 因为没装助手被拒绝时，任务卡片附上同样的提示。
- **笔记关系图**：笔记详情可打开以当前笔记为中心的关系图（直接链接或两层），只读现有的单篇链接接口，第二层最多展开 24 个邻居、共 80 篇；私密开关与列表一致，悬空链接不画。
  图用浏览器自带 SVG 手写布局（分层 / 力导向），不引入图形依赖；节点可点击与键盘打开，滚轮缩放（页面内需 ⌘/Ctrl）、拖动平移。知识页另有全库「列表 / 图谱」切换（ADR 0040，K3）：一次读取 human 专用图谱接口，沿用类型与私密开关，可隐藏孤立笔记；
  节点按类型着色、按链接次数之和定大小，最多保留连接数最高的 300 篇并明确提示裁剪。布局分批让出主线程，筛选切换、关闭私密和离开图谱时作废过期请求与布局。
- **删除**（ADR 0038，D1-5）：任务、项目、可编辑笔记和对话的列表项提供删除，按钮在悬停、键盘焦点进入或触屏设备上显示；确认框写明后果，删除后的提示可撤销。「最近删除」页（`#trash`，入口在设置的「数据」分类与命令菜单，返回键回到设置；侧栏不再单独放入口，PR #120）可恢复或彻底删除，彻底删除需再次确认。
- **推送**（ADR 0031，R4-5）：`/sw.js` 只处理推送与点击跳转，不缓存；CSP 允许 `worker-src 'self'`。通知规则见 [work.md](work.md)。
- **部署**：前端资源构建时嵌入 `lumio` 程序，随 Hub 一起提供与升级（ADR 0027）。
- **App**：提供 Web App Manifest 与图标，可安装到桌面或主屏幕；除恢复副本外不缓存业务数据。原生 Mac App 以后另定（ADR 0027）。
- **手柄**（G1-0）：手柄按键映射到与键盘快捷键、命令面板相同的界面命令，不新增权限；键位保存在本浏览器。高权限审批、彻底删除等危险操作不能单键完成，需长按确认并照常展示完整内容。页面不可见时停止读取手柄。
- **麦克风**（ADR 0055）：只在安全上下文（HTTPS 或 localhost）中提供录音入口，否则隐藏并说明原因；没有配置语音 Profile 时不显示入口，设置页写明音频发给哪个服务商。
- **共用工作台**（ADR 0060）：页面结构不变，主对话常驻。消息附带焦点快照（整包 UTF-8 ≤ 8 KiB，选中文字 ≤ 512 字素簇，Hub 复验），计入请求快照，不能作为批准证据；输入框上方显示焦点标签，人可以去掉或固定。
  展示工具（`ui.navigate` / `ui.highlight` / `ui.show` / `ui.clear`）只在主对话中提供给内置助手。Hub 发事件前校验路由名单、助手对每个 ID 的可见性，搜索结果须来自本轮工具结果；浏览器再用人的凭据读取内容。动作不改数据、不需审批。
  事件只投给发起该轮的标签页；该页失焦、断线或人正在输入、编辑、滚动时，跳转降级为"带我过去"按钮；跳转可后退返回。需要确认的事在当前页面原地弹出卡片。
  主动展示（assistant-reliability 第五阶段）：以发送时页面和时间判断本轮导航；发送前的活动不阻止讨论对象打开，发送后的手动切页、活动、未保存编辑或失焦优先保留人的位置。已在目标页不重复导航；切换主对象清掉旧相关面板，关闭或替换展示后使旧异步读取失效。
  提醒（A1-5）：重要提醒插进主对话（同一条在本标签页只出现一次）；Today 的「待处理」列出未读的非静默提醒，规则判为重要的已在「需要你处理」里，不重复；页面上有未读提醒的对象行带圆点，打开对象即标为已读。来源说明（探索结果、巡检等）由客户端按界面语言显示。焦点指向想法、任务或项目时可「帮我探索」。
- **收藏夹**（ADR 0065，I2-3）：Inbox 不分拣，不提供深读；资料页以原链接为阅读入口，存档文本在次要菜单中查看。
- **边界**：Web 不自行运行 agent，通过 Hub 显式委派。

## 原生 Assistant（ADR 0041、0042、0047）

- **设置页二级菜单**：分为通用、通知、AI 模型、Hub 与执行器、已连接的 agent、数据、关于；地址为 `#settings/<分类>`。桌面左侧分类、右侧内容；窄屏先显示分类列表，进入分类后返回键回到列表。各分类首次打开时才加载。
- 设置页统一管理 Connection/Profile；Assistant 选择 API 或原生 Profile。新对话从设置页的 Connection 复用官方登录，网页登录不持有官方认证；动态模型与思考档位来自执行器报告。
- Web 的新对话默认选择用户在当前浏览器为该 Hub 和账号指定的 Profile（M1-0）。未设置时由用户在发送前选择。Hub 旧 API 设置仍供兼容入口使用。
- 已保存原生状态、公开思考摘要、工具进度和审批在同一对话展示；不能用刷新/重连重发未知消息。审批与核查表单轮询时保留输入，发送前检查会话 ready；模型不支持的档位需重新选择。

- 新对话首次发送自动建原生线程；打开历史时按需恢复。同一个停止入口取消 API 或中断 Codex，等待确认后显示终态；手动压缩放在高级菜单（ADR 0047）。
- Profile、模型与思考强度在聊天输入区底部排成一行紧凑胶囊（窄屏换行），强度显示为本地化档位，应用于下一条消息，保留对话和 Profile 的默认设置。Assistant 在回复所在的行内先显示「等待模型」，有思考片段才显示「正在思考」，此时状态就写在折叠区标题上，结束后标题恢复为区域名；没有正文前不显示光标。DeepSeek 思考原文和原生 Codex 摘要共用按轮次折叠的区域。DeepSeek 片段仅在当前页面显示，原生摘要沿用可恢复的事件历史（ADR 0050）。
